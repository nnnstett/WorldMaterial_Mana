# semantic-tests/

LLM を使って、具体ケースへ世界法則を適用したときの意味整合性を検証するための定義群。

- `schemas/`: 候補回答・採点回答の JSON Schema
- `templates/`: 候補 LLM・採点 LLM へ渡す固定指示
- `public/`: リポジトリ管理するケース（`cases/*.json`、1ファイルに `ask`＝候補に見せる／`key`＝見せない）

候補 LLM の実行時にリポジトリ、Web、過去セッションを読ませない運用では、`public/` を通常の
回帰スイートとして使用できる。ただし、公開済みの `key` を学習済み・記憶済みのモデルに対する
秘密性までは保証しない。その脅威も対象にする場合だけ、リポジトリ外の非公開スイートを使う。

読者向け `FAQ.md`（リポジトリ直下）は `make faq` でこのケース群から生成する（`key` を出すので
候補には渡さない）。

実行手順、スイート形式、カンニング対策は
[LLM セマンティック検証](../docs/semantic-validation.md)を参照。
