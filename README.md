# World Material "Mana"

## はじめに

***プレリリースであり、メモ書きやToDoが残っています。***

私たちの世界の裏側にある異次元「真界」、そこに満ちる根源の力「マナ」、心の力が起こす魔法、そして宇宙の誕生すら一つの魔法だったという仮説——本ドキュメントは、そんな魔法世界の舞台設定を、少数のルールから一貫して組み上げた設定資料集です。物語・漫画・ゲーム・小説の土台として自由に使えます。

オープンソースとして公開していますので、[ライセンス](/LICENSE.md)に従う限り再利用や改変は自由となります。

## 設計思想

本プロジェクトの世界設定は、少数の根本前提（公理）から各設定要素を論理的に導出する体系として構成されています。
記述は次の 4 分類で整理されます。

- **公理 E（存在に関するもの）**: 何が存在するか（現界・真界・マナ・個体・魂・精神エネルギー）
- **公理 I（相互作用に関するもの）**: 何が起きうるか（変換則・共鳴則・副産則・作用則）
- **定理 T**: 公理から導出される世界の法則（エネルギー保存則・共鳴現化・存在強度・マナ還元・魔法・魔術・超能力など）
- **未解明領域 Q**: 物語ギミックや派生作品での改変余地として、体系内に意図的に確保された空白

これら世界の根本ルールに加えて、そこから生まれる具体的な中身（魔法・魔術・超能力・遺物・ダンジョン・種族・歴史）を記述しています。

この構造により、多様な設定要素が少数の前提から一貫した論理で説明されます。
新たな設定を追加する際にも、既存の公理・定理との整合性を確認することで、世界全体の一貫性を維持できます。

東アジアの「気」の概念、西洋的な二元論（真界/現界）、現代物理学の概念（エネルギー保存則、反物質）を統合した独自の体系です。
特定の文化や既存のファンタジー作品に依存するのではなく、「少数の前提から論理的に導出される体系」であることが本プロジェクトの特徴です。

導出構造の全体像と推奨される読み順は[導出構造マップ](world/README.md)を参照してください。
