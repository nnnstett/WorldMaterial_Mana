# 定理

本書は、この世界で**何が必然的に成り立つか**（定理＝世界の法則。[T1 エネルギー保存則]〜[T6 同調], [T10 集合無意識], [T11 瘴気動態]）と、**その力の使い方の呼び名**（行使形態の定義。[T7 魔法]〜[T9 超能力]）を定める。

定理は、公理が単独では述べていない一歩（公理を組み合わせて新しく言えること・世界全体へ広げられること・そこから従う帰結）だけを命題として主張する。現象そのものは公理が定め、定理はそれを引用する。各定理には**導出元**と**証明スケッチ**を付し、どの公理からどう導かれるかを追えるようにする（証明スケッチは読み飛ばしても本文は読める。スケッチ内の `公理群#項目名` 形式のリンクは、その公理群の中の特定の項目を指す）。

定理の**詳細**の箇条は命題・導出元から導かれる内容を示し、用語・観測事実・目安・補足・空白は役割ごとの区分として分ける。区分は定理直下と節の中のそれぞれで用いる（凡例は [world/README.md「役割ラベルの凡例」](../README.md#役割ラベルの凡例) を参照）。導出構造の全体像は [world/README.md](../README.md) を参照。

## 導出される法則

公理の組み合わせから必然的に成り立つ、世界の法則。定理の番号は名前の一部であり、並びは番号の順ではなく読み流れの順である。

### [T1] エネルギー保存則

**命題**: 「真界のマナ＋現界の物質・エネルギー＋現界の瘴気」の総量は常に一定である。

**導出元**: [I1 変換則] + [I3 副産則]

**証明スケッチ**:
- [I1 変換則#現出時変換] と [I1 変換則#量の保存] により、マナは現界に出る瞬間に物質・エネルギーへ変換される。この変換は量を保つ
- [I3 副産則#等量発生] により、変換時には対となる瘴気が必ず発生する。収支は「マナ減 ＝ 物質・エネルギー増 ＋ 瘴気増」で釣り合う（→ [I1 変換則#量の保存]）
- [I3 副産則#結合還元] により瘴気は物質・エネルギーと結合してマナへ戻り、[I1 変換則#量の保存] によりこの逆向きの変換も量を保つ（瘴気減 ＋ 物質・エネルギー減 ＝ マナ増）

**詳細**:
- 現界単体で見ると、現化（→ [T2 共鳴現化]）した物質・エネルギーの総量 ＝ 発生した瘴気の総量という対称性が成り立つ（→ [I3 副産則]）
- 瘴気は、釣り合い（結合力と存在強度。→ [I3 副産則]）の範囲の結合相手がある時だけマナへ戻り、なければ現界に残る。還元は物質・エネルギーと瘴気を同量ずつ消費するため、この対称性は崩れない
- 存在強度（→ [I5 継承則]）で保持されている物質も、対となる瘴気は消えずに現界に残り、命題の「現界の瘴気」として計上される

**補足**:
- 日常空間に瘴気の影響が現れにくいのは、ビッグバン由来物質と対の瘴気がほぼ不活性であるためである（→ [T11#活性と不活性]）

**関連**:
- → [T4 マナ還元], [T5 存在強度]

### [T2] 共鳴現化

**命題**: 使用された精神エネルギーがマナと共鳴することで、マナが魂（孔）を通り、方向づけられた物質またはエネルギーとして現界に現出する。

**導出元**: [E4 個体] + [E5 魂] + [E6 精神エネルギー] + [I1 変換則] + [I2 共鳴則] + [I6 現出則]

**証明スケッチ**:
- [E4 個体#帯有と使用] と [E6 精神エネルギー#発生] により、意思を持つ個体は精神エネルギーを発生させ、使用（意思による方向づけ）できる
- [I2 共鳴則#使用限定] と [I2 共鳴則#駆動] により、使用された精神エネルギーはマナ（→ [I2 共鳴則#向きと相手]）と共鳴し、変換を駆動する。変換先は精神エネルギーの方向が決める（→ [I2 共鳴則#変換先と効率]）
- [E5 魂#孔] と [E5 魂#大きさ] により、魂は真界と現界をつなぐ孔として働き、一度に扱えるマナ量の上限を定める
- [I1 変換則#現出時変換] により、マナは現界に現出する瞬間、必ず物理エネルギーまたは物質に変換される
- [I6 現出則#出現位置]・[I6 現出則#状態指定]・[I6 現出則#形成過程] により、生成物は駆動した個体が知覚している場に、方向の定める状態で現れ、物質であれば既存の物質を押しのけながら形を成す
- ゆえに、使用された精神エネルギーの駆動により、マナが魂の孔を通り、方向づけられた物質・エネルギーとして、知覚している場に現出する

**詳細**:
- 経路は「真界のマナ → 魂（孔）→ 物質またはエネルギー」であり、使用された精神エネルギーがこの変換を駆動する（→ [I2 共鳴則]）
- 現出の規模は、注ぎ込んだ精神エネルギーの量・強さ・変換効率がいずれも大きいほど大きい。効率を左右するのは、個体の側では真度・変換先と個体の方向性との整合・魂の形の適合度である（→ [I2 共鳴則]。場の側の制約は → [E3 マナ]）。一度に扱えるマナ量の上限は、魂の大きさが定める（→ [E5 魂]）
- 行使は注ぎ込んだ精神エネルギーを消費する。続けて行使できる量は、発生と容量に縛られる（→ [E6 精神エネルギー]）
- 生成物は駆動した精神エネルギーの裏付けを宿し、存在強度を持つ（→ [I2 共鳴則], [T5 存在強度]）
- 生成物が現れる場所・状態・形成の進み方は [I6 現出則] が定める。知覚が確かな場ほど狙いは精密になり、自らの占める場は最も確かに感じ取れる

**定義**:
- **現化**: マナが物質・エネルギーとして現界に現出すること。魂と精神エネルギーを経由する現化が本定理の**共鳴現化**であり、経由しない現化が自然現化（→ [T3 自然現化]）である

#### 重要な帰結: 知覚の外への現化の不可能性

感じ取れていない場は、現化の場にならない。物質・エネルギーを他個体の体内に直接現す行使が通常成立しないのは、この帰結の代表である。

- 他個体の内側は、通常、外の個体には感じ取れない（→ [I6 現出則]）。煙や闇、遮蔽の向こうも同じく、感じ取れなくなれば現化の場から外れる
- エネルギーで体内を攻めるには、体表など感じ取れる場に現し、物理法則に従って伝えるほかない（変化部分の帰結は → [T5 存在強度]）
- 例外は、相手の内側を現に感じ取るに至った者に限られる（内側も知覚の場になれば、そこに現化できる）

**観測事実**:
- 他個体の内側をそこまで感じ取った例は、読み取り（→ [I4 作用則]）を極めたごく稀なものだけが知られる

#### 特殊事例: ビッグバン

本世界で最大の魔法は、宇宙そのものの誕生である。

- 「現界」（[E1 現界]）自体も一つの個体（[E4 個体]）であり、意思を持ち精神エネルギーを使用できるため、共鳴現化を行使できる

**観測事実**:
- この宇宙の起源（ビッグバン）は、「現界」自身の精神エネルギーで行使された共鳴現化である。ゆえに**ビッグバンは魔法**であり、[T7 魔法] の最大事例にあたる
- ビッグバンで生成された物質は「現界」の精神エネルギーに裏付けられ、その存在強度は桁違いに高い（→ [T5#ビッグバン由来物質の還元不可能性]）

**空白**:
- 現界がビッグバンに先立って精神エネルギー・魂をどう備えたかは定義していない（→ [Q7 現界による宇宙生成の先行性]）

**関連**:
- → [E4 個体], [T5 存在強度], [T7 魔法], [T8 魔術]

### [T3] 自然現化

**命題**: 真界（[E2 真界]）でマナが極端に濃くなった場所では、精神エネルギーの媒介なしにマナが現界へ染み出す（→ [E3 マナ]）。この変換は方向づけを持たず確率的で、生成物は精神エネルギーの裏付けを持たない。

**導出元**: [E3 マナ] + [I1 変換則] + [I2 共鳴則] + [I6 現出則]

**証明スケッチ**:
- [E3 マナ#染み出し] により、局所濃度が極端に高くなったマナは、魂の孔を通らず溢れるように現界へ染み出す。この染み出しに方向づけはない
- [I1 変換則#現出時変換] と [I1 変換則#無方向現出] により、染み出したマナも現界に現出する瞬間、物理エネルギーまたは物質に変換される。共鳴を経ないため、何に・どの状態で変換されるかは確率的となる
- [I2 共鳴則#使用限定] と [I2 共鳴則#裏付け] により、裏付けを与えるのは使用された精神エネルギーの共鳴に限られる。それを欠く自然現化の生成物は裏付けを持たず、存在強度が極めて低い
- [I6 現出則#形成過程] は物質の変換一般に働くため、染み出した物質も形成として進み、押しのけに要するエネルギーを賄えない場では現れない。一方、[I6 現出則#出現位置] と [I6 現出則#状態指定] は共鳴を経た現化に限られ、駆動する個体も方向も持たない自然現化には働かない

**詳細**:
- 周囲の個体が帯びる未使用の精神エネルギーは共鳴を駆動しない（→ [I2 共鳴則]）ため、後から自然現化に方向性を与える媒介も存在しない
- 出現位置を定める規則は駆動する個体の知覚に依るため（→ [I6 現出則]）、それを持たない染み出しは、現れる場も染み出したその場所のままである
- 地中の岩盤の内側のような塞がれた場では、押しのけ・圧縮に大きなエネルギーを要する分だけ物質は形を成しにくく、成立しなかった変換ではマナは消費されず、瘴気も生じない

**観測事実**:
- 火山噴火・異常気象の一部など、自然災害的現象として現れる

#### 危険性

自然現化の生成物の性質から、次の帰結が導かれる（→ [T4 マナ還元], [T5 存在強度]）。

- 生成物は裏付けを持たず存在強度が極めて低いため、優先結合（→ [I3 副産則]）により真っ先に還元の的になる
- 現出と同時に等量の瘴気が発生する（→ [I3 副産則]）ため、生成物のそばには常に結合相手の活性瘴気（→ [T11 瘴気動態]）がある
- 還元の過程で、周囲の存在強度の低い物質を巻き込みうる（→ [T4#優先結合則]）
- ゆえに自然現化は周囲の生態系・建造物に対して破壊的でありうる

**関連**:
- → [T4 マナ還元], [T5 存在強度], [T11 瘴気動態], [Q6 マナ濃淡変動]

### [T4] マナ還元

**命題**: 瘴気が物質・エネルギーと結合してマナへ戻ること＝還元（→ [I3 副産則]）は、自然反応としてだけでなく、精神エネルギーで駆動する意図的な操作（**真化**）としても起こせる。

**導出元**: [I3 副産則] + [I2 共鳴則] + [E6 精神エネルギー]

**証明スケッチ**:
- [I3 副産則#結合還元] により、瘴気は物質・エネルギーと結合してマナへ戻る。ただし瘴気自身の結合力は小さく、自然に結合できる相手は釣り合い（→ [I3 副産則#釣り合い]）の範囲に限られる
- [I2 共鳴則#向きと相手] と [I2 共鳴則#真化の結合力] により、使用された精神エネルギー（→ [I2 共鳴則#使用限定]）は真化の向きで瘴気と共鳴し、結合力を高める。高まりは強さが高いほど大きい（→ [I2 共鳴則#強さと働き]）
- ゆえに、自然には結合が成立しない相手にも、精神エネルギーの駆動によって結合＝還元を意図的に引き起こせる。これが真化である

**詳細**:
- 経路は「瘴気 ＋ 物質・エネルギー → マナ（真界へ）」である（→ [I3 副産則]）
- 真化は行使者を選ぶ。真度が浅い個体ほど瘴気と共鳴しやすく（→ [I2 共鳴則]）、扱う対象に合った魂（[E5 魂]）の形と、対象の存在強度に見合う強さを要する
- 現化が真界の膨大なマナを引くだけで成立するのに対し、真化は還元する対象と結合相手の瘴気がともに現界に在って初めて成立し、現化の完全な裏返しではない（結合相手の瘴気がどこに在るかは → [T11#生成物の存続と移動]）

**定義**:
- **真化**: 精神エネルギーの駆動によって、還元を意図的に引き起こす操作。現化（→ [T2 共鳴現化]）と対をなす
- **還元力**: 真化において、駆動で高められた実効的な結合力（→ [I3 副産則]）

**補足**:
- 語の整理: 結合力＝瘴気側の働き、存在強度＝相手側の抵抗（→ [I3 副産則]）、還元力＝高められた結合力、強さ＝術者側の濃さ（→ [E6 精神エネルギー]）

#### 還元判定

真化で対象を狙って消せるかは、次の釣り合いで決まる。

- 前提: 対象と結合相手の活性瘴気（まだ反応しうる瘴気。→ [T11 瘴気動態]）が、ともに到達範囲（→ [I3 副産則]）に在ること
- 真化が対象を還元できるかは、術者の**還元力**が対象の存在強度を上回るかで決まる。[I3 副産則] の釣り合いを、駆動で高められた結合力に当てはめた帰結である
- 還元力は、精神エネルギーの強さ（→ [E6 精神エネルギー]）と、真化方向の効率（真度の浅さ・方向の特化。→ [I2 共鳴則]）がともに高いほど大きい（例: 魔法で生んだ氷は消せるが、ビッグバン由来の岩には届かない）
- この判定は、ビッグバン由来物質の還元不可能性（→ [T5#ビッグバン由来物質の還元不可能性]）の根拠となる

#### 優先結合則

- 瘴気は、到達範囲内で最も存在強度の低いものから優先して結合し、存在強度が釣り合いを上回る相手とは自然には結合しない（→ [I3 副産則]）
- この公理から、次の帰結が導かれる:
  - 魔法で生成した低存在強度の物質は、通常の物質が残るなかで真っ先に還元され、消える
  - 瘴気が蓄積した環境（→ [dungeons.md]）では生成物が安定しにくい
  - 自然現化の生成物が真っ先に還元の的になる危険性（→ [T3#危険性]）も、この選別による

**関連**:
- → [T1 エネルギー保存則], [T2 共鳴現化], [T5 存在強度], [T11 瘴気動態], [T7 魔法], [T8 魔術], [dungeons.md]

### [T11] 瘴気動態

**命題**: マナ変換で生じた瘴気は発生地点に滞留してゆっくり広がり、結合しうる相手へ緩やかに引き寄せられる（→ [I3 副産則]）。生成物がいつ・どこで還元されるかは行く先も含めどの活性瘴気にいつ出会うかで決まり、存在強度は移動では変わらず（→ [I5 継承則]）、供給が絶えれば裏付けも弱まる（→ [I2 共鳴則]）ため、到達範囲の外への移動は延命にはなっても恒久化の手段にはならない。

**導出元**: [I2 共鳴則] + [I3 副産則] + [I5 継承則]

**証明スケッチ**:
- [I3 副産則#等量発生] と [I3 副産則#近傍滞留] により、瘴気は生成物と重なる位置に等量で生まれ、発生地点の近傍に滞留して、到達範囲内の相手とのみ結合しうる。広がりと引き寄せはいずれも緩慢で、物の運搬や射出よりはるかに遅い（→ [I3 副産則]）
- [I3 副産則#優先結合] と [I3 副産則#釣り合い] により、結合は到達範囲内で最も存在強度の低い相手から順に、釣り合いの範囲で進む
- [I5 継承則#物理過程不変] により、存在強度は移動や物理過程では変わらない（弱まりは → [I2 共鳴則#裏付けの維持]）。ゆえに移動それ自体は消えやすさを変えず、いつ・どこで消えるかは、どの活性瘴気にいつ出会うかで決まる

**定義**:
- **活性瘴気**: まだ結合相手と反応しうる状態の瘴気
- **不活性瘴気**: 不活性化（→ [I3 副産則]）して、ほぼ相互作用しなくなった瘴気

#### 活性と不活性

- 活性瘴気は発生地点の近傍に滞留し、到達範囲内にある結合相手とのみ反応する（→ [I3 副産則]）
- 不活性瘴気は、物質とも魔法のはたらきともほぼ相互作用しない背景在庫となるが、[T1 エネルギー保存則]の「現界の瘴気」には計上され続ける
- 持続的にマナが消費される環境では、活性瘴気は生成と不活性化の釣り合いへ向かう水準まで蓄積しうる（→ [dungeons.md]）

**観測事実**:
- ビッグバン由来物質と対をなす膨大な瘴気は、ほぼ全量が不活性である

**目安**:
- 不活性化までの期間は環境に依存し、数十年〜数百年のオーダーである

**空白**:
- 不活性瘴気が再活性化する条件は確認されていない（→ [Q13 不活性瘴気の再活性化]）

#### 生成物の存続と移動

生成物が消えるか・いつ消えるかは、瘴気の分布（→ [I3 副産則]）と存在強度（消えにくさの度合い。→ [T5 存在強度]）で決まる。

- 現化の生成物は、自分と重なって生じた等量・最高濃度の瘴気の中で生まれる（→ [I3 副産則]）。瘴気は濃いほど結合が速く進み、多くの場合その場で最も存在強度の低い相手は生成物自身であるため、優先結合（→ [I3 副産則]）により生成物が最初の的になる——通常の使い方で生成物が速やかに消えるのはこのためである
- 発生した瘴気の到達範囲の外へ出た生成物（高速の射出や搬送、エネルギーの伝播）は、その瘴気からは還元されない（結合は到達範囲内の共存に限られる。→ [I3 副産則]）。ただし存在強度は移動では変わらず（→ [I5 継承則]）、供給が絶えれば裏付けも弱まっていく（→ [I2 共鳴則]）
- 魔法が使われる土地では、現化のたびに撒かれた瘴気が低い存在強度の物へ引き寄せられていく。近くに相手のない瘴気は遠く離れた孤立した生成物へも緩やかに向かう（→ [I3 副産則]）ため、壁や小部屋に隠しても長期には守れず、生成物はいずれ削られる
- 十分に遠く、魔法の使われない土地まで運ばれた生成物は、裏付けが弱まりきっても、瘴気に出会わなければ物としては残りうる（引き寄せは緩慢で、瘴気は届く前に不活性化しうる）。高い存在強度を保ち続けられるかは、移動ではなく供給の続く支えがあるかで決まる（→ [T5 存在強度]）
- 取り残された瘴気は、到達範囲内の次の相手と結合するか、相手を得なければ不活性化へ向かう（→ [T11#活性と不活性]）

**関連**:
- → [T1 エネルギー保存則], [T2 共鳴現化], [T4 マナ還元], [T5 存在強度], [dungeons.md], [magic.md]

### [T5] 存在強度

**命題**: 物質・エネルギーは、存在強度（→ [I5 継承則]）が高いほど瘴気との結合＝還元から保たれ、還元は存在強度の低いものへ集中する。この保持と選別が、何が消えて何が残るかを定める。

**導出元**: [I2 共鳴則] + [I3 副産則] + [I5 継承則]

**証明スケッチ**:
- [I3 副産則#釣り合い] と [I3 副産則#優先結合] により、瘴気の結合は釣り合いを上回る相手とは自然には成立せず、到達範囲（→ [I3 副産則#近傍滞留]）内で最も存在強度の低い相手から優先して結合する
- [I2 共鳴則#裏付け] と [I2 共鳴則#裏付けの度合い] により、共鳴を経た生成物の存在強度は、駆動した精神エネルギーの強さを主要因として決まる
- [I2 共鳴則#裏付けの維持] により、裏付けは供給が絶えると弱まる
- [I5 継承則#物理過程不変] と [I5 継承則#現在値] により、存在強度は物理過程を越えて部分ごとに受け継がれ、[I3 副産則#優先結合] の選別は来歴や構造を問わず現在の値だけを見る
- ゆえに、裏付けが強く保たれているものは残り、弱いものから順に消える——存在強度は、世界の「消えにくさ」の尺度として働く

**詳細**:
- 既存物質にマナ由来のエネルギーが作用した場合、既存物質は自身の高い存在強度で保護され、変化部分の存在強度は術者の精神エネルギー次第となる（例: 魔法の熱で木を燃やすと、木は還元されず、熱は術者次第）
- 魔法生成物は、混ざっても、化合しても、取り込まれても低いまま真っ先に還元される（→ [I5 継承則]。環境に撒かれた瘴気との出会いは → [T11#生成物の存続と移動]）。魔法の生成物で飲食や恒久の財をまかなえないのはこのためである。逆に、魔法が引き金・触媒・道具として働いただけの結果は、ビッグバン由来ゆえ高いまま残る（→ [magic.md]）
- 一度の裏付けだけで高い存在強度は保ち続けられない。保たれるのは供給源となる個体が在り、支え続けている間だけである——「現界」が保つビッグバン由来物質、自らを支える意思ある道具（→ [artifacts.md]）がその例である
- 肉体本体はビッグバン由来で存在強度が高いため消えないが、体内・周囲の低存在強度の物質（魔法生成物など）が還元に巻き込まれて生体の働きが乱されるのが瘴気の毒性である。精神エネルギーが弱く、生成・維持する物の存在強度を保ちにくい個体ほど影響を受けやすい（→ [dungeons.md]）
- 優先結合の選別は原子核の内側の部分にも及びうる。魔法由来の陽子・中性子を含む核では、還元が核の不安定化・崩壊を誘発しうる（伝説級の例外事象で、日常の物質には起きない）

**観測事実**:
- 多くの個体から認知される存在は、集合無意識（→ [T10 集合無意識]）からの供給で存在強度が支えられる（宛先機構は未解明。→ [Q8 集合無意識の宛先機構]）。効くのは魔法・魔術の生成物や術式などの付与部分で、ビッグバン由来の部分には及ばない（例: 万人に知られる聖剣は付与部分が支えられて力を保つ。→ [artifacts.md]）

#### 重要な帰結: ビッグバン由来物質の還元不可能性

真化で消せるのは存在強度の低い物（魔法・魔術の生成物）だけであり、通常の物質は消滅させられない。

- ビッグバン由来の物質は「現界」の精神エネルギーで保持され（→ [T2 共鳴現化]）、その存在強度は個々の個体が支えるものとは桁違いに高い
- 原理の上では、術者の**還元力**（→ [T4#還元判定]）が上回ればビッグバン由来物質も還元できるが、世界そのものの保持を上回る持ち主は歴史上確認されておらず、実質的に不可能である
- ただしワープなど、真化した同一の対象が欠損なく同時に現化する操作は「消滅」ではなく「移動」であるため抵触しない（機構は未解明。→ [Q12 転送の機構], [magic.md]）
- 一部の伝説の武具は、方向を極限まで特化させて還元力を高め、この制限を一部超える（ただし「現界」を上回ることはない。→ [artifacts.md]）
- 種全体の真度が遠い未来まで浅化し続けた極限では、真化方向の還元力が「現界」の保持に届き、ビッグバン由来物質の還元に至りうる——という時間スケールの仮説がある（確定した帰結ではない。機構・時期は未解明。→ [Q10 真度浅化の行く末]）

**関連**:

### [T6] 同調

**命題**: 精神エネルギーが他個体の魂に接続し、その魂を自分の魂の代わりに用いてマナの変換（現化・真化）を行う現象。

**導出元**: [E5 魂] + [E6 精神エネルギー] + [I2 共鳴則] + [I4 作用則]

**証明スケッチ**:
- [I4 作用則#接続作用] と [I4 作用則#位相と阻害] により、使用された精神エネルギー（→ [I4 作用則#使用限定]）は位相の近い他個体の魂へ接続できる
- [E5 魂#他魂アクセス] は、条件次第で他個体の魂へアクセスしうることを認める。このアクセスは、魂が持つ「孔」としての機能に及ぶ
- ゆえに、接続した先の魂を孔（→ [E5 魂#孔]）として、自分の精神エネルギー（[E6 精神エネルギー]）の共鳴（→ [I2 共鳴則#駆動]）を働かせられる

**詳細**:
- 経路は「自分の精神エネルギー → 他個体の魂（[E5 魂]）→ 接続成立」である
- 接続成立の条件は位相の近さである（→ [I4 作用則]）。位相は系譜を写すため、血縁や同種族の魂ほど接続が成立しやすい（→ [E6 精神エネルギー]）
- 規模上限は用いる魂の大きさと、対象の魂への到達可能性で決まる
- 同調した相手の魂は、現化（→ [T2 共鳴現化]）や真化（→ [T4 マナ還元]）のとき自分の魂の代わりに使える。借りるのは魂（孔）だけで、変換を駆動する精神エネルギーは自分のものである

**観測事実**:
- 代行者・調停者と呼ばれる種族は、親にあたる大規模な個体（母体）と完全に同調し、その魂を使って大規模な現化を行う（→ [races.md]）

**関連**:
- → [I4 作用則], [T2 共鳴現化], [T4 マナ還元], [T9 超能力], [races.md]

### [T10] 集合無意識

**命題**: 社会・文化圏のような上位の個体も、心の働きに応じて精神エネルギーを発生させ、欲求・衝動水準の方向づけによって無意識的に使用しうる。

**導出元**: [E4 個体] + [E6 精神エネルギー]

**証明スケッチ**:
- [E4 個体] の 3 要件と入れ子構造（[E4 個体#入れ子]）により、一体性を備えた社会・文化圏は上位の個体でありうる
- [E4 個体#帯有と使用] と [E6 精神エネルギー#発生] により、個体は心の働きに伴って精神エネルギーを発生させ、意思があれば使用できる。ここでの意思は欲求・衝動の水準でよい（→ [E6 精神エネルギー] の「使用」）
- ゆえに、上位の個体も、その心の働きに応じて精神エネルギーを発生させ、使用しうる

**定義**:
- **集合無意識**: 上位の個体が発生させ、構成個体の認知・想念の重なりを方向づけとして無意識的に使用する精神エネルギー

**観測事実**:
- 上位個体の心の働きは、構成個体の認知・想念の重なりとして実際に現れる。集合無意識の働きも実際に確認されており、多くの個体が認知・想念を向ける対象へ向かう（作用の経路は → [I4 作用則]。例は伝説の武具 → [artifacts.md](../artifacts.md)）
- 文化圏などの上位個体も一個の個体であり（→ [E4 個体]）、その集合無意識の真度は、いつ・どう形作られたか＝宇宙のルーツからの遠さで決まる（→ [E6 精神エネルギー]）。人代に成った文化圏の集合無意識は、真度が浅い（応用例は → [artifacts.md](../artifacts.md)）

**空白**:
- 集合無意識が個々の対象の存在強度をどのように支えるか（宛先の選択・集約の機構）は未解明である（→ [Q8 集合無意識の宛先機構]）
- 上位個体が、欲求・衝動を超えた「意思」と呼べる水準の方向づけを持つかは未解明である（→ [Q15 上位個体の魂と意思]）

**関連**:
- → [E4 個体], [E6 精神エネルギー], [I4 作用則], [T2 共鳴現化], [T5 存在強度], [Q8 集合無意識の宛先機構], [Q15 上位個体の魂と意思], [Q17 個体化の下限], [artifacts.md](../artifacts.md), [spellcraft.md](../spellcraft.md)

## 行使形態の定義

マナの変換（現化・真化）や魂への作用を、誰が・どう行使するかへの命名。導出される法則ではなく名前の**定義**であり、**定義**と**定義対象**を本書に置き、体系・規模・具体例などの詳細は応用ファイルに委ねる。公理・定理を組み合わせて新しい主張を立てるものが法則（例: [T6 同調]）であり、既に導かれた変換・作用の行使に名前を与えるものが本節の定義である。

### [T7] 魔法

**定義**: 個体が、術式などの外部の仕組みによる精神エネルギーのシフト（→ [T8 魔術]）を介さず、自身の精神エネルギーで直接マナの変換（現化・真化）を行使する場合、これを「魔法」と呼ぶ。

**定義対象**: [T2 共鳴現化]・[T4 マナ還元] の行使のうち、術式を介さず個体自身の精神エネルギーによるもの

**詳細**:
- 自身の精神エネルギーを直接使うため、術式によるシフト（→ [T8 魔術]）の損失（→ [I2 共鳴則]）がなく効率は破格である。一方、精神エネルギーの方向が素養に依存するため、複雑な操作には不向きである

**補足**:
- 体系・規模・暴走・具体例などの詳細は [magic.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T4 マナ還元], [T6 同調], [T8 魔術], [magic.md]

---

### [T8] 魔術

**定義**: 術式によって変換された精神エネルギーでマナの変換（現化・真化）を行使する場合、これを「魔術」と呼ぶ。

**定義対象**: [T2 共鳴現化]・[T4 マナ還元] の行使のうち、術式を介するもの

**詳細**:
- 駆動する精神エネルギーは使用者自身が使用したものである（→ [I2 共鳴則]）。術式（→ [spellcraft.md]）がその属性（真度・位相・方向）をあらかじめ定めた値へシフトするため、誰でも同じ現象を発現できる
- シフトは損失を伴う（→ [I2 共鳴則]）ため、効率は魔法に劣る

**補足**:
- 術式の定義そのものと詳細は [spellcraft.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T4 マナ還元], [T7 魔法], [spellcraft.md], [artifacts.md]

### [T9] 超能力

**定義**: 個体が自身の精神エネルギーを、マナの変換（現化・真化）を経ずに他個体（およびその魂）へ直接作用させる場合、これを「超能力」と呼ぶ。

**定義対象**: [I4 作用則] の接続・作用の行使

**詳細**:
- マナを扱う術ではなく、魔法・魔術とは作用経路が異なる
- 接続を起点に、情報を読み取る方向、個体に変化を与える方向、接続・作用を遮る防御として体系化される

**観測事実**:
- 行使できる個体は極めて稀である。何がこの発現を分けるのかは未解明である（→ [Q14 超能力の発現条件]）

**補足**:
- 各形態の定義・射程・抵抗などの詳細は [psionics.md] に委ねる

**関連**:
- → [I4 作用則], [T6 同調], [Q14 超能力の発現条件], [psionics.md]
