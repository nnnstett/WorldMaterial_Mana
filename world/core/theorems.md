# 定理

本書は[公理](axioms.md)から論理的に導出される世界の法則（**定理**）を定義する。各定理には**導出元**を明記し、公理からの導出関係を追えるようにする。

魔法・魔術・超能力の**定義**（[T7 魔法], [T8 魔術], [T9 超能力]）は命題と導出元のみを本書に置き、詳細は応用ファイルに委ねる。

導出構造の全体像は [world/README.md](../README.md) を参照。

---

### [T1] エネルギー保存則

**命題**: 「真界のマナ＋現界の物質・エネルギー＋現界の瘴気」の総量は常に一定である。

**導出元**: [I1 変換則] + [I3 副産則]

**証明スケッチ**:
- [I1 変換則] により、マナは現界に出る瞬間に物質・エネルギーへ変換される（マナ減 ＝ 物質・エネルギー増）
- [I3 副産則] により、変換時には対となる瘴気が発生する（物質・エネルギー増 ＋ 瘴気増 で保存）
- 瘴気がマナに戻る場合も対称的に保存される（瘴気減 ＋ 物質・エネルギー減 ＝ マナ増）

**詳細**:
- 現界単体で見ると、瘴気の総量 ＝ 現化した物質・エネルギーの総量という対称性が成り立つ
- 瘴気は、より存在強度の低い結合相手がある時だけマナへ戻り、なければ現界に残る（→ [T4#優先結合則]）。ゆえに現化した物質が現界にある限り対の瘴気も現界に残り、総量が保存される
- 存在強度（[T5 存在強度]）で保持されている物質も、対となる瘴気は消えずに現界に残り、命題の「現界の瘴気」として計上される。結合相手を得られないまま長期間が経った瘴気は不活性化する（→ [T4#活性と不活性]）。ビッグバン由来物質と対をなす膨大な瘴気はほぼ全量が不活性であり、日常空間に瘴気の影響が現れないのはこのためである

**関連**:
- → [T4 マナ還元], [T5 存在強度]

### [T2] 共鳴現化

**命題**: 魂を経由した精神エネルギーがマナと共鳴することで、マナが物質またはエネルギーとして現界に現出する。

**導出元**: [E5 魂] + [E6 精神エネルギー] + [I1 変換則] + [I2 共鳴則]

**詳細**:
- 経路は「真界のマナ → 魂（孔）→ 精神エネルギー（共鳴・触媒）→ 物質またはエネルギー」である
- 効率を決める要素は、精神エネルギーの量・真度・方向、および魂（[E5 魂]）の大きさと形の適合度である
- 自身の精神エネルギーを使う場合は[T7 魔法]、術式で変換した精神エネルギーを使う場合は[T8 魔術]となる

#### 特殊事例: ビッグバン

本世界で最大の魔法は、宇宙そのものの誕生である。

- 「現界」（[E1 現界]）自体を一つの個体（[E4 個体]）と見たとき、その精神エネルギーで行使された共鳴現化が宇宙の起源（ビッグバン）である
- ゆえに**ビッグバンは魔法**であり、[T7 魔法] の最大事例にあたる
- ビッグバンで生成された物質は「現界」の精神エネルギーで存在強度が極限に保たれる（→ [T5#ビッグバン由来物質の還元不可能性]）
- 「ビッグバン由来の物質」は本世界の特殊な分類として、応用ファイルで頻繁に参照される
- 現界がビッグバンに先立って精神エネルギー・魂をどう備えたかは定義していない（→ [Q7 現界による宇宙生成の先行性]）

**関連**:
- → [T5 存在強度], [T7 魔法], [T8 魔術]

### [T3] 自然現化

**命題**: 真界でマナが極端に濃くなった場合、精神エネルギーの媒介なしに現界へ染み出すことがある。

**導出元**: [E3 マナ]（高濃度のマナが溢れ出す性質）＋ [I1 変換則]

**詳細**:
- 発生条件は、真界（[E2 真界]）の局所的なマナ濃度が極端に高いことである。このとき高濃度のマナは、魂（[E5 魂]）の孔を介さず、溢れるように現界へ染み出す（→ [E3 マナ]）
- 火山噴火・異常気象の一部など、自然災害的現象として現れる
- 媒介となる精神エネルギーがないため、変換の方向性は確率的で予測不能である
- 周囲の個体が帯びる未使用の精神エネルギーは共鳴の触媒にならない（→ [I2 共鳴則]）ため、自然現化に方向性を与える媒介は存在しない

#### 危険性

- 自然現化で生成された物質・エネルギーは精神エネルギーの裏付けがなく、存在強度（[T5 存在強度]）が極めて低い
- 即座に瘴気と反応してマナに戻ろうとする
- その過程で周囲の存在強度の低い物質を巻き込んでマナ還元してしまう（→ [T4#優先結合則]）
- ゆえに自然現化は周囲の生態系・建造物に対して破壊的でありうる

**関連**:
- → [T4 マナ還元], [T5 存在強度], [Q6 マナ濃淡変動]

### [T4] マナ還元

**命題**: 瘴気が物質または物理エネルギーと結合することで、マナの状態に戻り真界に収められる。

**導出元**: [I3 副産則] + [I2 共鳴則]

**証明スケッチ**:
- 自然反応による還元: [I3 副産則] が「瘴気は物質・エネルギーと結合してマナへ戻る」ことを保証する
- 意図的な還元（真化。現化の逆操作にあたる）: [I2 共鳴則] の共鳴が逆方向にも働くことで、精神エネルギーを触媒として還元を引き起こせる

**詳細**:
- メカニズムは「瘴気 ＋ 物質・エネルギー → マナ（真界へ）」である
- 還元には、瘴気と低存在強度の物質が自然反応する場合と、精神エネルギーを触媒として意図的に起こす場合（真化）がある。真化は、現化（→ [T2 共鳴現化]）と対になる操作である
- 還元のしやすさは対象の存在強度（[T5 存在強度]）に依存する
- 真化（還元方向）では、精神エネルギーは瘴気（→ [I3 副産則]）と共鳴して対象（低存在強度の物質）との結合を促す。真度が浅い個体ほど成立しやすい（向きと真度の対応は → [I2 共鳴則]）。ただし現化が真界の無尽蔵なマナを引くだけで成立するのに対し、真化は還元する対象と結合相手の瘴気が現界に在って初めて成立するため、現化と完全な裏返しではない。真化も、扱う対象に合った魂（[E5 魂]）の形と、対象の存在強度に見合う強さを要する
- 真化が対象を還元できるかは、術者の**還元力**（精神エネルギーの強さに真化方向の効率＝真度の浅さ・方向の特化を掛けた実質的な力）が、対象の存在強度（[T5 存在強度]）を上回るかで決まる

#### 優先結合則

- 瘴気は周囲の最も**存在強度が低いもの**から優先的に結合する
- 結合先がない場合（周囲が全て高存在強度）は瘴気として残留する
- この性質は次の現象を生む:
  - 魔法で生成した低存在強度の物質は通常より速く消滅する
  - 瘴気が蓄積した環境（ダンジョン等）では生成物が安定しにくい
  - 自然現化（[T3 自然現化]）の危険性の根拠となる

#### 活性と不活性

- 発生直後の瘴気（**活性瘴気**）は発生地点の近傍に滞留し、到達範囲内にある結合相手とのみ反応する（→ [I3 副産則]）。[優先結合則](#優先結合則)の「周囲」はこの到達範囲を指す
- 長期間（環境に依存するが、目安は数十年〜数百年のオーダー）結合相手を得られなかった瘴気は**不活性化**し（→ [I3 副産則]）、物質とも魔法環境ともほぼ相互作用しない背景在庫となる。不活性瘴気も[T1 エネルギー保存則]の「現界の瘴気」に計上され続ける
- ビッグバン由来物質と対をなす膨大な瘴気は、ほぼ全量が不活性である
- 持続的にマナが消費される環境では、活性瘴気は生成と不活性化の釣り合いで定まる水準まで蓄積する（→ [dungeons.md]）
- 不活性瘴気が再活性化する条件は確認されていない

**関連**:
- → [T1 エネルギー保存則], [T5 存在強度], [dungeons.md]

### [T5] 存在強度

**命題**: マナから変換された物質・エネルギーは、精神エネルギーの影響を受けた度合い（存在強度）に応じて、瘴気との結合のされにくさが決まる。

**導出元**: [E6 精神エネルギー] + [I3 副産則] + [T2 共鳴現化]

**詳細**:
- 存在強度とは、物質・エネルギーが精神エネルギー（[E6 精神エネルギー]）の影響を受けている度合いである
- 存在強度を決める要素:
  - **主要因**: 術者の精神エネルギーの強さ
  - **副次的要因**: 精神エネルギーの方向と魂（[E5 魂]）の形の適合度
  - **影響しない**: 真度・位相。真度は共鳴で扱えるマナの量＝規模や真化の還元力を、位相は他個体への接続のしやすさを左右するが、生成物に精神エネルギーが刻まれる度合い＝存在強度は強さで決まる。ゆえに真度・位相は生成物の安定性には中立
- 多くの個体から認知される存在は、結果として存在強度が高い（例: 万人に知られる聖剣）。集合無意識から精神エネルギー供給を受けるためと考えられるが、その宛先機構は未解明である（→ [Q8 集合無意識の宛先機構]）
- 既存物質にマナ由来のエネルギーが作用した場合、既存物質はビッグバン由来の存在強度で保護され、変化部分の存在強度は術者の精神エネルギー次第となる
- 瘴気は[T4#優先結合則]により最も存在強度の低いものから結合する。肉体本体はビッグバン由来で存在強度が高いため消えないが、体内・周囲に生じた低存在強度の物質（魔法生成物など）は還元に巻き込まれうる
- この巻き込みによって生体の働きが乱されるのが瘴気の毒性であり、肉体の崩壊ではなく機能の阻害である。精神エネルギーが弱く、生成・維持する物の存在強度を保ちにくい個体ほど影響を受けやすい（詳細は応用ファイルで扱う）

#### 重要な帰結: ビッグバン由来物質の還元不可能性

真化で消せるのは存在強度の低い物（魔法・魔術の生成物）だけである。その理由と、例外・遠未来の思弁を以下に示す。

- ビッグバン由来の物質は「現界」自体の精神エネルギーで保持され、存在強度が極限に高い
- 魔法・魔術で対象を還元できるかは、術者の**還元力**（→ [T4 マナ還元]）が対象の存在強度を上回るかで決まる。ビッグバン由来物質は「現界」自体に支えられており、これを上回る還元力を持つ個体は存在しないため、還元は実質的に不可能である
- 帰結として次が成り立つ:
  - 真化は通常の物質を消滅させられず、有効な対象は魔法・魔術で生み出された低存在強度の物質に限られる（→ [magic.md]）
  - ただしワープなど真化と現化を厳密に同時に行い、現界の物質・エネルギーの総量を保つ操作は、「消滅」ではなく「移動」であるため抵触しない——と整理されている。なぜこの操作だけが制限を逃れるのか、機構は解明されていない（→ [magic.md]）
  - 一部の伝説の武具は、方向を極限まで特化させて還元力を高め、この制限を一部超える（ただし「現界」を上回ることはない。→ [artifacts.md]）
- ここまでは現在の個体一人ひとりの話で、誰も「現界」を超えられない。これとは別に、種全体の真度が遠い未来まで浅化し続けたら、という時間スケールの仮説がある（確定した帰結ではない）。その極限では真化方向の還元力が「現界」の保持にまで届き、ビッグバン由来物質＝現界そのものの還元（現界の崩壊）に至りうる。機構・到達の可否・時期はいずれも未解明である（→ [Q10 真度浅化の行く末]）

**関連**:
- → [T4 マナ還元], [T7 魔法], [magic.md], [artifacts.md], [dungeons.md]

### [T6] 同調

**命題**: 精神エネルギーが他個体の魂にアクセスし、その個体の情報・感覚・意思に接続する現象。

**導出元**: [E5 魂] + [E6 精神エネルギー] + [I2 共鳴則] + [I4 作用則]

**詳細**:
- 経路は「自分の精神エネルギー → 他個体の魂（[E5 魂]）→ 接続成立」である
- 接続成立の条件は、位相の近さと関係性（血縁・同種族・継続的な関わり等）である
- 接続後にできることは、情報受信・感覚共有・（条件次第で）意思の伝達である
- 完全同調の場合は双方向となり、互いに影響を与え合う
- 規模上限は自分の魂の大きさと、対象の魂への到達可能性で決まる
- 特殊事例として、代行者・調停者は母体の魂と完全同調できる（→ [races.md]）

**関連**:
- → [I4 作用則], [T9 超能力], [races.md]

### [T7] 魔法

**命題**: 個体が自身の精神エネルギーで[T2 共鳴現化]を行使する場合、これを「魔法」と呼ぶ。

**導出元**: [T2 共鳴現化] の応用（個体自身の精神エネルギーによる行使）

**詳細**:
- 自身の精神エネルギーを直接使うため効率は破格だが、精神エネルギーの方向が素養に依存するため複雑な操作には不向きである
- 限定的な条件下（相手との位相の近さが条件）では他個体の魂も利用できる
- 体系・規模・暴走・具体例などの詳細は [magic.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T8 魔術], [magic.md]

---

### [T8] 魔術

**命題**: 術式によって変換された精神エネルギーで[T2 共鳴現化]を行使する場合、これを「魔術」と呼ぶ。

**導出元**: [T2 共鳴現化] の応用（術式を介した行使）

**詳細**:
- 術式は精神エネルギーの属性（真度・位相・方向）をあらかじめ定めた値へシフトする人工的プログラムであり、誰でも同じ現象を発現できる一方、変換ロスにより効率は魔法に劣る
- マナは術式が刻まれた道具の魂を経由して取り出される
- 術式の定義そのものと詳細は [spellcraft.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T7 魔法], [spellcraft.md], [artifacts.md]

---

### [T9] 超能力

**命題**: 個体が自身の精神エネルギーを、マナを介さずに他個体（およびその魂）に直接作用させる場合、これを「超能力」と呼ぶ。

**導出元**: [I4 作用則] の応用

**詳細**:
- マナを扱う術ではなく、魔法・魔術とは作用経路が異なる
- 形態は、接続の基盤（感応）を起点に、受信（知覚拡張）と作用（支配）に分かれる
- 詳細は [psionics.md] に委ねる

**関連**:
- → [I4 作用則], [T6 同調], [psionics.md]
