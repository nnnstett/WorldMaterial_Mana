# 魔法

術式などの外部の仕組みを介さず、個体が自身の精神エネルギーで直接マナの変換（[現化](core/axioms.md#i1-変換則)・[真化](core/axioms.md#i3-副産則)）を行使することを「魔法」と呼ぶ（定義は [T7 魔法](core/theorems.md#t7-魔法)）。マナの変換には、マナから物質・物理エネルギーを生み出す現化と、それらをマナへ還す真化の両方向がある（現界に現れるので現化、真界のマナへ還るので真化である）。本書は魔法の規模・体系・具体例と、生成物の行く末・暴走・人代での姿を扱う。なお、この世界で最大の魔法は宇宙の誕生（ビッグバン）そのものである（→ [T2 共鳴現化#特殊事例: ビッグバン](core/theorems.md#特殊事例-ビッグバン)）。

## 魔法とは

- 魔法を使う人や個体を**魔法使い**と呼ぶ。
- 自身の精神エネルギーを直接使うため、術式によるシフトの損失がなく、効率は破格である（→ [T7 魔法](core/theorems.md#t7-魔法)）。一方、精神エネルギーの方向は個体自身の方向性に強く引っ張られる（→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）ため、複数の方向を組み合わせる複雑な行使は難しい（できないわけではない）。
- 同調（→ [T6 同調](core/theorems.md#t6-同調)）が成立していれば、マナの変換の際に、自分以外の魂も孔として使える。

## 魔法の規模

一度の行使の規模は、注ぎ込んだ精神エネルギーの量・強さ・変換効率がいずれも大きいほど大きい（→ [T2 共鳴現化](core/theorems.md#t2-共鳴現化)）。

- **量**: 留めている精神エネルギー（上限は容量。→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）を元手として、一度の行使に注ぎ込んだ量。留めている分まで注ぎ込めるため、注ぎ込める量の上限は容量で決まる。注ぎ込んだ分は消費されて戻らず、心の働きに伴う発生で回復する。消費が回復を上回れば、行使は続かない。
- **強さ**: 精神エネルギーの濃さ（→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）。量が同じでも、強さが高いほど働きは大きい。
- **変換効率**: 個体の側では、真度（現化では深いほど、真化では浅いほど共鳴しやすい）・扱う種類（現化では変換先、真化では還す相手の種類）と個体の方向性との整合・魂の形の適合度で決まる（→ [I2 共鳴則](core/axioms.md#i2-共鳴則)）。場の側の条件は向きで異なり、現化ではその場所に対応する真界のマナ濃度が引き出せる量と効率を制約し（→ [E3 マナ](core/axioms.md#e3-マナ)）、真化では還元する対象と活性瘴気がともにその場に在ることを前提とする（→ [T4 共鳴真化](core/theorems.md#t4-共鳴真化)）。

このほかに、一度の行使は二つの上限の内に収まる。注ぎ込める精神エネルギーは容量までであり、一度に通せるマナ量は魂の大きさが定める（現化で引き出す量・真化で還す量のいずれも。→ [E5 魂](core/axioms.md#e5-魂)）。容量は鍛錬で増えるが、魂の大きさは個体の生成時に定まり、訓練や成長では変わらない。

## 魔法の体系

魔法は、現化を行使する**現化魔法**と真化を行使する**真化魔法**に大別され、変換・還元の対象が物質かエネルギーかで四つに分かれる。この四分類は、古代に確立され、人代に断片的に伝わった体系に基づく（→ [magic-history.md 魔法の体系化](magic-history.md#魔法の体系化)）。このほかに、四分類のどれにも属さない例外として、現化と真化を同時に行う複合の行使が知られている（→ [転送（ワープ）](#転送ワープ)）。

### 現化魔法

- マナを物質または物理エネルギーに変換して現象を起こす魔法。何になるかは、精神エネルギーの方向が決める（→ [I2 共鳴則](core/axioms.md#i2-共鳴則)）。
- 生成物が現れる位置・状態・形成の進み方は [I6 現出則](core/axioms.md#i6-現出則) に従う。術者が現に直接感じ取っている場所にだけ現れ、感じ取れていない場所（他個体の内側はその代表）には現れない（→ [T2 共鳴現化#知覚の外への現化の不可能性](core/theorems.md#重要な帰結-知覚の外への現化の不可能性)）。
- 物質を現すには、その場の空気や水を押しのけるエネルギーまで込みで賄う（→ [I6 現出則](core/axioms.md#i6-現出則)）。固体の中や隙間なく塞がれた場では押しのけに大きなエネルギーを要してほとんど形を成せず、既存の物を壊して場所を作るにも同じだけの負担がかかる。現化は無償の破壊の近道にならない。
- 生成物の存在強度は、駆動した精神エネルギーの裏付け次第である。人型の平均的な強さの裏付けなら、供給が絶えると秒単位で弱まり（→ [I5 保持則](core/axioms.md#i5-保持則)）、生成物は、生成と同時に重なる位置へ生じた等量の瘴気（→ [I3 副産則](core/axioms.md#i3-副産則)）の最初の的になって、通常は速やかにマナへ還る（→ [T11 瘴気動態#生成物の存続と移動](core/theorems.md#生成物の存続と移動)）。
- 生成物は、術者が精神エネルギーを使用して支え続ける（供給。→ [I5 保持則](core/axioms.md#i5-保持則)）ことで保てる。維持している間も消費は続き、他の行使と元手を食い合う。

#### 物質化

- マナを物質に変換する魔法。
- 方向の指定は、物質の種類だけでなく温度・相・初期の運動までの状態に及ぶ（→ [I6 現出則](core/axioms.md#i6-現出則)）。炎天下に氷を現すこともでき、現れた後は物理法則に従う（融けていく）。
- 初期の運動を指定しなければ、生成物は術者に対して静止して現れ、疾走する馬上でも術者とともにある。生成の瞬間に術者と同じ速度を帯びるという意味であり、現れた後まで術者を追いはせず、物理法則に従う。地面や標的を基準にした運動を帯びさせて現すのは、方向づけの技巧に属する。
- 難易度は、生成する物質の複雑さに応じて上がる。単純な物質（水、金属の塊など）は比較的容易だが、複雑な構造を持つ物質（生体組織、精密な機構など）は極めて困難で、構造への深い理解と、それに対応する精密な方向制御を要する。状態まで細かく定めるほど、必要な方向制御も精密になる。

#### エネルギー化

- マナを物理エネルギーに変換する魔法。最も基本的かつ使いやすい現化魔法であり、魔法の中で最も広く使われる。
- 熱・運動・光のような単純な物理エネルギーほど方向づけが容易で、変換効率も高い。
- エネルギーの現出は、場所の押しのけを要さずその場に現れ、物理法則に従って伝わる（→ [I6 現出則](core/axioms.md#i6-現出則)）。現れる場が術者の知覚している場に限られる点は物質と同じで、相手に熱を届けるには、体表など知覚の届く場に現し、物理の伝わりとして及ぼす形になる。
- 既存物質に作用して生じた変化部分（加熱された空気が帯びる熱など）は、それ自体が独立した存在強度を持ち、安定するかは術者の精神エネルギーの強さに依る。既存物質の本体は、ビッグバン由来の高い存在強度で守られる（→ [T5 存在強度](core/theorems.md#t5-存在強度)）。
- 変化部分が還元されて元に戻るのも、活性瘴気（まだ結合相手と反応しうる瘴気。→ [E8 瘴気](core/axioms.md#e8-瘴気)）が届く場合である。熱や光は、変換点に生じた瘴気を残して伝わっていく（→ [T11 瘴気動態#生成物の存続と移動](core/theorems.md#生成物の存続と移動)）。点火された化学反応のような二次的な物理反応の結果は、物理法則に従って残る。

### 真化魔法

- 共鳴真化（→ [T4 共鳴真化](core/theorems.md#t4-共鳴真化)）により現象を起こす魔法。対象の物質・物理エネルギーを瘴気と結合させてマナに還元し、その消失として現象を起こす（例: 熱エネルギーの還元による冷却）。極端な場合は、対象そのものの消滅に等しい。
- 対象を還元できるのは、結合相手となる活性瘴気が対象に届いている場合に限られ、そのうえで、術者の還元力が対象の存在強度を上回っている必要がある（→ [T4 共鳴真化#還元判定](core/theorems.md#還元判定)）。存在強度の高い対象ほど、還元のハードルは高い。結合は成立しうる相手の低い順に進むため、供給の絶えた弱い物がそばにあればそちらが先に還るが、方向・魂の形の適合を絞れば、絞りの外の物を残したまま狙った種類だけを還せる。
- 本領を発揮するのは、敵の魔法・魔術が生んだ低存在強度の物を打ち消す場面や、還元対象と瘴気の豊富なダンジョンの内である（→ [dungeons.md](dungeons.md)）。瘴気のない場では、そもそも真化が成立しない。

#### 真化魔法の制限

- ビッグバン由来の物質・物理エネルギーには還元力が届かず、実質還元できない（→ [T5 存在強度#ビッグバン由来物質の還元不可能性](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性)）。
- ゆえに真化魔法が有効なのは、原則として、魔法や魔術で生み出された物質・物理エネルギーに対してのみである。日常の通常物（ビッグバン由来）は消せない。

#### 物質還元

- 物質を瘴気と結合させてマナに還元する魔法。対象の存在強度を上回る還元力を要し、方向が還元する物質の種類に適合しているほど還元力は高まる（→ [T4 共鳴真化](core/theorems.md#t4-共鳴真化)）。
- 単純な物質ほど還元しやすく、複雑な構造の物質は部分的にしか還元できないことが多い。魔法や魔術で生成された物質は存在強度が低く、比較的容易に還元できる。

#### エネルギー還元

- 物理エネルギーを瘴気と結合させてマナに還元する魔法。対象の熱エネルギーを還元して周囲を冷やすなど、対象からエネルギーを取り除く形で現象を起こす。
- エネルギー化と同様に、単純な物理エネルギーほど還元しやすい。魔法や魔術で発生させた物理エネルギーは存在強度が低く還元が容易であり、真化魔法の中では最も実用的である。

### 現化・真化の複合

#### 転送（ワープ）

現化と真化の複合魔法。行使できた個体の記録は数えるほどしかなく、桁違いの存在の証とされる。

行使しうるのは、複数の孔を持つ魂（→ [E5 魂](core/axioms.md#e5-魂)。孔がなぜ複数生じるかは [Q9 複数孔の魂](core/open-questions.md#q9-複数の孔を持つ魂の発生原理)）の持ち主だけである。機構は、対象を一方の孔で真化し、**厳密に同時に**もう一方の孔で現化する、というものである。この同時の二重操作に孔が二ついるため、孔が一つの魂には行使できない。対象の構造情報は、術者の精神エネルギーが方向として保持し続ける（マナは、あらゆる姿に変わりうる「可能性」そのものであり、特定の姿を留めるものではない。→ [E3 マナ](core/axioms.md#e3-マナ)）。

真化したその対象が、そのまま現化に現れる。同じ対象について真化と現化が厳密に同時に成り立つため、対象の履歴は途切れず、着いたものは元と同一の個体である（→ [E4 個体](core/axioms.md#e4-個体)）。別物にすり替わる「消滅と再生」ではなく、一つの個体の「移動」である。移動である以上、対象が帯びていた存在強度（→ [E7 物質・物理エネルギー](core/axioms.md#e7-物質物理エネルギー)）も部分ごとにそのまま保たれ、通常の現化のような新たな裏付けは加わらない。現化を経ながら裏付けが置き換わらない理由も、本節末尾の未解明の機構（→ [Q12 転送が還元不可能性に抵触しない機構](core/open-questions.md#q12-転送が還元不可能性に抵触しない機構)）の一部である。

出現側は、通常の現化と同一の規則（→ [I6 現出則](core/axioms.md#i6-現出則)）に従う。目的地は術者が現に直接感じ取っている場に限られ、他個体の内側は通常感じ取れないため、敵の体内へ送り込む使い方は成立しない（→ [T2 共鳴現化#知覚の外への現化の不可能性](core/theorems.md#重要な帰結-知覚の外への現化の不可能性)）。対象は、真化の瞬間の状態（運動の勢いを含む）のまま現れる。術者の精神エネルギーが保持する対象の状態が、そのまま方向による状態の指定（→ [I6 現出則](core/axioms.md#i6-現出則)）となるためで、指定なしの現化に働く「術者に対して静止」の既定はここには当てはまらない。状態まで等価に保たれてはじめて「移動」となる。

収支は通常の変換と同じく閉じる。出発地で対象を、結び合う瘴気（→ [I3 副産則](core/axioms.md#i3-副産則)）とともにマナへ真化し、目的地でそのマナから対象を、対の瘴気とともに現化する。対象と対の瘴気は出発地で消えて目的地に等量生じ、着地時に空気や水を押しのけるぶんのエネルギーは、これとは別に真界から引かれて対の瘴気を伴う。

成立には、さらに次の条件を要する。

- 他個体を転送するには対象の魂への接続が前提であり、同調（→ [T6 同調](core/theorems.md#t6-同調)）と同等の位相適合を要する。接続は相手の精神エネルギーに阻害される（→ [I4 作用則](core/axioms.md#i4-作用則)）ため、抵抗する敵対者を一方的に転送することは実質不可能
- 生体の転送は、現化の難易度則（→ [物質化](#物質化)）の頂点にあたる。生体組織の完全な再構成を要し、通常の物質化とは比較にならない精度の方向制御が要求される

ビッグバン由来の物質を対象とする場合は、通常の真化魔法の制限（現界の存在強度を超えられない）との関係が問題になる。真化したその対象が欠損なく現化に現れる限り、現界のビッグバン由来の物質は減らず、「消滅」ではなく「移動」であるため、現界の精神エネルギーによる保持は破られない、と整理されている。なぜこの操作だけが制限を逃れるのか、機構は未解明である（→ [Q12 転送が還元不可能性に抵触しない機構](core/open-questions.md#q12-転送が還元不可能性に抵触しない機構)）。

## 魔法の例

### 現化魔法の例

#### 物質化の例

- **水の生成**: マナを水（H₂O）に変換する魔法。物質化の中では比較的シンプルな構造であるため、難易度は低い部類に入る。並の術者が生成した水は存在強度が低く、生まれたての重なった瘴気の中では数秒で還元されて消える。体内に取り込んでも存在強度は低いまま残り、還元のとき巻き込みが体の働きを乱しうるため（瘴気の毒性。→ [T5 存在強度](core/theorems.md#t5-存在強度)）、飲用には適さない。消火や一時的な障壁としては使われる。
- **金属の生成**: マナを金属に変換する魔法。単一元素の金属（鉄、銅など）であれば中程度の難易度だが、合金や精密な構造を持つ金属製品の生成は極めて困難。一時的な盾や武器として戦闘中に用いられることがある。

#### エネルギー化の例

- **火炎**: マナを熱エネルギーに変換する魔法。方向が「熱」というシンプルなものであるため最も基本的な魔法の一つで、素養がある者であれば比較的容易に習得できる。熱エネルギーが周囲の空気や物質に作用することで炎として顕在化する。
- **衝撃**: マナを運動エネルギーに変換し、特定方向に力を発生させる魔法。火炎と同様に方向がシンプルで基本的な魔法に分類される。運動エネルギーの方向と強度の制御が精度を左右する。
- **地震**: マナを運動エネルギーに変換し、地面に作用させる魔法。原理は衝撃と同じだが、広範囲に力を分散させる必要があるため、より大きな規模の精神エネルギーを要する。精密な制御が難しく、術者自身も影響を受けうる。

### 真化魔法の例

#### 物質還元の例

- **防壁破壊**: 魔法や魔術で生成された物質（壁、障壁など）を瘴気と結合させてマナに還元する魔法。対象の存在強度が低ければ比較的容易だが、存在強度の高い物に対しては困難である。多くの個体に認知され、その重なる想念（集合無意識。→ [T10 集合無意識](core/theorems.md#t10-集合無意識)）に存在強度を支えられた物（→ [T5 存在強度](core/theorems.md#t5-存在強度)）が典型である。

#### エネルギー還元の例

- **冷気**: 対象の熱エネルギーを瘴気と結合させてマナに還元し、対象や周囲を冷却する魔法。火炎の真化版とも言え、方向は「熱」に対応する。還元できるのは魔法・魔術で付加された存在強度の低い熱（生成された火炎など）であり、ビッグバン由来物質が本来持つ熱は「現界」の精神エネルギーに保持された高存在強度のため、実質的に還元できない（→ [T5 存在強度#ビッグバン由来物質の還元不可能性](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性)）。日常環境の物質を冷やす効果が限定的なのはこのためである。

## 生成物の行く末の例（存在強度の継承）

魔法の生成物がその後の物理変化を経たときに何が残るかは、各部分がどちら由来かで決まる（存在強度の継承。→ [I5 保持則](core/axioms.md#i5-保持則), [T5 存在強度](core/theorems.md#t5-存在強度)）。合言葉は「魔法製は魔法製、天然は天然」である。以下、「天然」はビッグバン由来の通常の物質を指し、人が精錬・加工した物も、素材がビッグバン由来なら「天然」に含む。魔法製部分の存在強度の高低は生成時の術者次第で、表は典型的な低強度の場合を示す。魔術の生成物も同様である（→ [spellcraft.md](spellcraft.md)）。

| ケース | 帰結 |
|---|---|
| 魔法の光が物に当たり熱に変わる | 熱（変化部分）は低いまま還元され、加熱前の温度に近づく。着火など二次反応の結果物は天然由来なので恒久に残る |
| 魔法生成物を触媒に天然物質が反応する | 反応生成物は天然由来で恒久。触媒は反応では消費されないが、魔法製なので後で還元されて消える（「消える触媒」） |
| 魔法の塩を水に溶かし、再結晶させる | 溶けても析出しても魔法の塩は低いまま。再結晶しても恒久化しない |
| 魔法の水を天然の瓶に入れて運ぶ | 瓶は天然なので残る。水は低いまま、行く先で活性瘴気に出会えば瓶の中でも還元される（容器は遮蔽にならない） |
| 魔法の金属を天然金属と合金にする | 魔法原子だけが還元されて抜け、空隙だらけの脆い天然金属が残る |
| 魔法の材料が混ざった高分子（プラスチックなど） | 魔法由来の単位が還元されて鎖が切れる。安定した魔法入りの高分子は作れない |
| 魔法の酸素を呼吸する | 取り込んでも代謝しても低いまま。いずれ還元されるとき、組み込まれた先が損なわれる（瘴気の毒性）。身体の材料として当てにできない |
| 魔法の材料が細胞・生体組織に組み込まれる | 組み込まれても低いまま還元され、その箇所が損傷する。魔法材料から恒久的な生体は作れない |
| 魔法由来の陽子・中性子を含む原子核（伝説級） | 還元が核の不安定化・崩壊を誘発しうる（→ [T5 存在強度](core/theorems.md#t5-存在強度)）。崩壊で生じる原子核やエネルギーは天然由来側で、本物である |

上の表は、発生した瘴気や周囲の活性瘴気が生成物・変化部分に届く、通常の状況での帰結である。運び出しで延命はできても消えにくさは変わらないこと、魔法の使われる土地では生成物がいずれ削られ、使われない土地まで運ばれれば物として残りうることは、[T11 瘴気動態#生成物の存続と移動](core/theorems.md#生成物の存続と移動) が定める。人知れず残る魔法製の品は、その帰結の一例である。また、連続して生成を行う工房では、対の瘴気がその場に溜まり続ける（蓄積の帰結は → [dungeons.md](dungeons.md)）。

## 魔法の暴走

魔法行使時に精神エネルギーの制御が失われ、意図しない現象が発生することを暴走と呼ぶ。

**発生要因**:

- 精神エネルギーの方向制御の失敗（意図しない方向への変換）
- 意図した量を超えて精神エネルギーを注ぎ込み、意図した以上の変換を駆動してしまう
- 精神的動揺や肉体的限界による制御喪失

**結果**:

- 意図しない物理エネルギーや物質が大量に生成される
- 大量の瘴気が同時に発生し、周囲の存在強度の低い物質を還元してしまう危険がある（→ [I3 副産則](core/axioms.md#i3-副産則)）
- 暴走の後には、大量の瘴気の残留と、既存物質に生じた物理的な変化が残りうる。使用された精神エネルギーは消費されて戻らないため（→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）、痕跡が変換を駆動し続けることはない
- まれに、暴走の生成物から暴走型ダンジョンが成立する（→ [dungeons.md 暴走型](dungeons.md#暴走型)）

**自然現化（[T3 自然現化](core/theorems.md#t3-自然現化)）との違い**:

- 自然現化は、真界のマナが極端に濃くなり、媒介なしに現界へ染み出す自然現象である。魔法の暴走は個体の魔法行使の失敗が原因であり、起点が異なる。

## 人代における魔法

- 魔法の行使自体は、原初返り（先天的に精神エネルギーの真度が深い個体。→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）でなくても原理上は可能である。しかし人代の人間の真度は極めて浅く、現化魔法に必要なマナとの共鳴は実質的に成立しない（→ [I2 共鳴則](core/axioms.md#i2-共鳴則)）。
- 真化魔法は、浅い真度でも原理的に行使可能である。しかし人代の日常環境の物質・物理エネルギーはほとんどがビッグバン由来であり、還元できる対象が実質存在しない（→ [真化魔法の制限](#真化魔法の制限)）。還元できる物と活性瘴気のそろう場では、この限りではない（→ [dungeons.md](dungeons.md)）。
- 結果として、人代の条件下（極めて浅い真度・身の回りの物質がほとんどビッグバン由来である環境）では、魔法は原理上可能でも実効的にゼロに近い。現化魔法を行使できるのは、原初返りの個体（1 世代に 2〜3 人程度）に限られる。
- 一般社会では、魔法の存在は認知されていない。
