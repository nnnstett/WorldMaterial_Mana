# 遺物・アーティファクト

## 遺物

- 神代・古代に存在した個体・道具・構造物のうち、その時代の精神エネルギーの痕跡を残して現存するもの
- 存在強度（→ [T5 存在強度](core/theorems.md#t5-存在強度)）が極めて高いため、長い年月を経ても瘴気によるマナ還元に抵抗し、現界に残り続けている。高い存在強度の由来は次のいずれか。
  - 強い精神エネルギーの持ち主（代行者・調停者など）が作り出したもの。存在強度は製作者の精神エネルギーの強さに由来する（→ [T5 存在強度](core/theorems.md#t5-存在強度)）
  - 多くの個体に認知・使用されたことで集合無意識（多くの個体に共有される意識の重なり。→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）の裏付けを持つもの
  - 強い精神エネルギーが封入されたもの
- なお、代行者・調停者が母体の魂を介して作った道具では、上記の存在強度とは別に、孔（魂）の大きさ＝魔術の規模上限も高くなる（仕組みは → [spellcraft.md 道具の魂の大きさ](spellcraft.md#道具の魂の大きさ)）。存在強度（瘴気への抵抗）と規模上限（一度に動員できるマナ量）は独立に効く。
- 遺物は道具に限らない。
  - 構造物（神殿、要塞、儀式場など）
  - 空間そのもの（強い精神エネルギーが空間に刻まれたもの）
  - 残留する精神エネルギーの痕跡

遺物のうち術式が刻まれた道具で、道具自体が精神エネルギーを供給するものは「伝説の武具・道具」として分類される（[後述](#伝説の武具道具)）。

遺物の周辺では魔法環境が変質する傾向がある。

- 遺物に刻まれた強い方向づけは一種の意思として働き、遺物が帯びる精神エネルギーを「使用された」状態に保ち続ける。意思を持たず精神エネルギーを使用しない通常の道具（→ [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)）と異なり、遺物の精神エネルギーは触媒として真界のマナと共鳴し続け（→ [I2 共鳴則](core/axioms.md#i2-共鳴則)）、周辺の魔法環境に影響を与える。
- この影響はダンジョン化の原因の一つとなる（→ [dungeons.md](dungeons.md)）。大規模な魔法・魔術の暴走が空間に刻んだ強い方向づけの痕跡も、高い存在強度を保つ間は同様に真界のマナとの共鳴を維持しうる

## 種子

- 代行者・調停者が、自身の全滅を予見して残した「次世代の個体を発芽させるための遺物」。
  - 代行者・調停者の精神エネルギーの痕跡と、母体（地球やエオス）の魂の方向性が封じ込められている
  - 特定の環境条件が満たされたときに発芽し、新たな個体・種族を生む
- 種子から発芽した個体は代行者・調停者の末裔としての性質を持つ。
  - 母体の魂の方向性を引き継ぐ
  - 精神エネルギーの位相が代行者・母体に近い傾向がある（→ [races.md](races.md)）

### 発芽条件

- 周辺の環境変化（対応する真界のマナの濃淡の変動、気候、生態系の変化など）
- 地球自身の意思による促進も影響する
- 発芽した個体がテリトリーを構築し、集落を形成することがある。このテリトリーがダンジョン化するケースがある（→ [dungeons.md B 種子由来](dungeons.md#b-種子由来)）。

### 種子の全発芽

- 古代にはベローナの代行者の活動による環境変化と地球の意図的促進により、複数の種子が同時に発芽した（→ [timeline.md](timeline.md)）。
  - エルフもエオスの代行者・調停者が残した種子から発芽した種族である。エオスの魂の方向性「成長・繁茂」が種子に封じ込められており、発芽した個体がこの方向性を引き継いでいる。
- 神代に残された種子はこの時期にすべて発芽済みである。
  - 発芽条件が自然に整わなかった種子も、地球の意思により強制的に発芽させられた
  - 環境に適応できなかった個体・種族はそのまま滅亡した
  - 原則として、人代において新たな種子の発芽が起きることはない（ただし未知の特殊な事情による例外の可能性は排除しない）

## 伝説の武具・道具

### 概要

- 術式が刻まれた道具のうち、道具自体が有意な量の精神エネルギーを供給する特殊なもの。
- 供給メカニズムの詳細は [spellcraft.md 道具自体が精神エネルギーを供給するケース](spellcraft.md#道具自体が精神エネルギーを供給するケース) を参照。
- 以下の精神エネルギー供給ケースに分類される。
  - ケースA: 存在強度が極めて高い道具が集合無意識から精神エネルギーを受信
  - ケースB: 製作時の魔術師の精神エネルギーが封入されている
  - ケースC: 道具自体が意思を持つに至った（発生原理は未解明 → [Q2 意思を持つ道具](core/open-questions.md#q2-意思を持つ道具ケース-cの発生原理)）
- いずれの武具も、供給・加算される精神エネルギーは存在強度の法則（→ [T5 存在強度](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性)）の上限に服し、「現界」の保持（ビッグバン由来物質の還元）を超えることはできない。

### 一覧

#### エクスカリバー

- **ケース**: A（集合無意識）
- **精神エネルギー源**: 「選定の剣」として万人に知られることによる極めて高い存在強度。集合無意識から精神エネルギーを受信する
- **特性**:
  - 使用者の資質（精神エネルギーの強さと方向性）に応じて出力が変動する
  - 使用者の精神エネルギーと剣が受信する集合無意識の精神エネルギーが相乗する構造
  - 「正統な王」としての認知が集合無意識を増幅するため、使用者の社会的立場も出力に影響する
- **術式**: 使用者の精神エネルギーを増幅する術式が刻まれており、集合無意識からの受信を使用者に還元する

#### 三種の神器（草薙剣）

- **ケース**: A + C
- **精神エネルギー源**: 国家レベルの集合無意識（「日本を守護するもの」としての認知）+ 「守護」という極限まで特化した意思
- **特性**:
  - 守護に特化するのは「守護」の集合無意識と意思（上記の精神エネルギー源）によるものであり、日本列島の魂の方向性に由来するのではない。守護に関する魔法の効率が極めて高い一方、攻撃的な用途には適さない
  - 日本列島という大規模な個体（地球の一部）との同調（→ [T6 同調](core/theorems.md#t6-同調)）を補助する。これは出力の方向を決めるものではなく、列島の大きな魂を使って規模を得るための別機能である
  - 使用者と日本列島の精神エネルギーの位相の差を術式が橋渡しすることで、通常は不可能な同調を実現する
- **術式**: 精神エネルギーの位相を日本列島の精神エネルギーに近づけるシフト機能を持つ

#### ミョルニル

- **ケース**: A + C
- **精神エネルギー源**: 「雷神の武器」としての集合無意識 + 「破壊」に極限まで特化した意思
- **特性**:
  - 現化魔法（エネルギー化: 電磁気エネルギー）に特化した武具
  - 術式が精神エネルギーの方向を「電磁気」に最適化するため、雷に関する魔法の効率が破格
  - 「破壊」の意思により、道具自体が精神エネルギーを発生させ、使用者の出力に加算される
- **術式**: 精神エネルギーの方向を電磁気エネルギーに変換する高効率な術式

#### ロンギヌスの槍

- **ケース**: C
- **精神エネルギー源**: 「貫く」という極限の意思。製作の経緯と歴史的な使用を通じて、この方向性が極限まで研ぎ澄まされた
- **特性**:
  - 真化魔法（還元）に特化した武具
  - 「貫く」という意思が極限まで特化することで、この方向に限り**還元力**（強さ×真化方向の効率）が極めて高くなり、通常の真化魔法では届かない高存在強度の対象に対しても還元を行える
  - ただし存在強度の法則（→ [T5 存在強度](core/theorems.md#t5-存在強度)）を覆すわけではなく、「現界」の精神エネルギーを超えることはできない。ビッグバン由来物質（→ [T5 存在強度#ビッグバン由来物質の還元不可能性](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性)）への還元はできない
- **術式**: 精神エネルギーをマナ還元の触媒として最適化する術式。対象の存在強度への干渉効率が極めて高い

#### 賢者の石

- **ケース**: B
- **精神エネルギー源**: 製作者の精神エネルギーが封入されている
- **特性**:
  - 使用者の魔法・魔術の出力をブーストする道具
  - 封入された精神エネルギーは使用により消耗するため、本質的には消耗品
  - ただし封入量が膨大であるため、実質的に数世代にわたって使用可能な場合もある
  - 意図的な製作は極めて困難であり、超希少
- **術式**: 封入された精神エネルギーを使用者の精神エネルギーに加算する術式
