# World Material "Mana" 設計書

本書は World Material "Mana" の世界設定ドキュメント群の**永続的な設計指針**を定める。世界の中身そのもの（公理・定理の本文）ではなく、

- ドキュメントをどう構造化するか
- 各公理・定理・未解明領域・応用ファイルに何を書くか

を規定する。本書を参照すれば、各ファイルの本文を直接書き始められる粒度の設計を備えることを目標とする。

## 1. 本書の役割と他ドキュメントとの関係

### 1.1 ドキュメント階層

| 階層 | ファイル | 内容 | 読者 |
|---|---|---|---|
| 設計（メタ） | `docs/architecture.md`（本書） | 構造・分類・各ファイルの設計仕様 | 執筆者・レビュアー |
| 著者の選択 | `docs/design-notes.md` | 公準的事項の集約 | 派生作品作者・執筆者 |
| 概念索引 | `glossary.md` | 全概念の索引 | 全読者 |
| 世界の本体 | `world/core/`, `world/*.md` | 公理・定理・応用 | 物語作者・興味読者（中学生〜） |

各ファイルの内部書式（design-notes.md のエントリ書式、glossary.md の章立てとタグ付けなど）は当該ファイル自体の冒頭で定義する。本書では「どのファイルに何を集約するか」までを規定する。

### 1.2 本書を変更する場合

世界の中身（公理・定理の命題そのもの、または重要な内部構造）を変更する場合、本書を**先に更新**してから実装する。設計と実装の乖離を避ける。

### 1.3 対象読者

世界の本体（`world/` 配下）の対象読者は次のとおり。

- **物語作者**: ゲーム・小説・漫画などで本世界設定を利用する執筆者
- **興味読者**: 中学生〜の一般読者。物語から世界設定に興味を持って読みに来る人

本書はこれら 2 層の読者に向けた本体ドキュメントを生成可能にする設計とする。すなわち、専門用語に頼らず、論理構造を保ちつつ平易に書ける構造を備える。

## 2. 分類体系

世界の根本（コア体系）を支える分類は 4 種のみ。これとは別に、特定のドメイン（魔法・魔術・超能力・遺物・ダンジョン・種族・歴史等）を扱う**応用層**が `world/` 直下にフラット配置される。応用層は分類接頭辞を持たず、ファイル単位で管理する。

| 接頭辞 | 名称 | 役割 | 配置 |
|---|---|---|---|
| **E** | 公理（存在に関するもの） | 何が存在するか | `world/core/axioms.md` |
| **I** | 公理（相互作用に関するもの） | 何が起きうるか | `world/core/axioms.md` |
| **T** | 定理 | 公理から導出される世界の法則 | `world/core/theorems.md` |
| **Q** | 未解明領域 | 意図的に答えを与えていない領域 | `world/core/open-questions.md` |

数学でいう「補題」「系」は採用しない。定理から直接導かれる短い帰結は、定理本文中の**節**として配置するか、応用ファイル内の該当節に置く（§7 で各定理に対して指定）。

### 2.1 core / 応用 の振り分け原則

| 観点 | core（公理・定理） | 応用 |
|---|---|---|
| 普遍性 | どの著者が書いても同じ | 著者の選択・観察事実を含む |
| 抽象度 | 世界の根本法則 | 特定の現象・存在の記述 |
| 数の増減 | 安定 | 将来増える可能性が高い |
| 派生作品での扱い | 改変すれば別世界 | 改変しやすい・足しやすい |

「魔法・魔術・超能力」は**定義**（短い命題）は core/theorems.md に T7〜T9 として置き、**詳細**（体系・暴走・具体例）は応用ファイル（`magic.md`, `spellcraft.md`, `psionics.md`）に置く。

## 4. 記述規約

### 4.1 命題本文の標準セクション順序

公理（E/I）・定理（T）の本文は、次の順序で書く。

| 順序 | セクション | 必須 | 内容 |
|---|---|---|---|
| 1 | 命題 | ◎ | 1〜2 文で簡潔に。何が成立するか |
| 2 | 導出元 | ◎（公理は除く） | どの公理・定理から導かれるか |
| 3 | 証明スケッチ | △ | 定理のみ。導出が自明でない場合 |
| 4 | 詳細 | ○ | 命題から論理的に必然な内容、補足説明（観測事実は 1〜2 文まで。詳細は §4.6 参照） |
| 5 | 重要な帰結（節） | △ | 定理のみ。§7 で各定理に対して指定 |
| 6 | 関連 | ◎ | 他の命題・応用ファイルへのリンク |

未解明領域（Q）は別構造（§4.5 参照）。

著者の選択（公準的事項）は本文に書かない。`docs/design-notes.md` に集約する。

### 4.2 応用ファイル冒頭の前提・関連リスト

応用ファイルは冒頭に、依存する公理・定理を明示する。

```markdown
*前提: [T7 魔法](core/theorems.md#t7-魔法), [E6 精神エネルギー](core/axioms.md#e6-精神エネルギー)*
*関連: [T5 存在強度#ビッグバン由来物質の還元不可能性](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性),
       [Q1 波長操作](core/open-questions.md#q1-波長を人為的に真界寄りにする方法)*
```

### 4.3 ID 付与・廃止・分割

- 各分類の末尾連番で追加（E7, I5, T10, Q7 など）
- 廃止された ID は再利用しない。ファイル内に `[廃止] T3 旧名称 — 移動先` の痕跡を残す
- 既存命題が肥大化した場合は分割記号（E3a, E3b 等）を使わず、新 ID を採番して旧 ID は廃止扱いとする
- 定理内「重要な帰結」節および応用ファイル内の節は**独立 ID を持たない**。安定したアンカー名で参照する

### 4.4 相互参照のリンク形式

| 場面 | 形式 |
|---|---|
| 同一ファイル内 | `[E1 現界](#e1-現界)` |
| `core/` 内の異ファイル | `[E1 現界](axioms.md#e1-現界)` |
| 応用 → `core/` | `[E1 現界](core/axioms.md#e1-現界)` |
| `core/` → 応用 | `[magic.md](../magic.md)` |
| 応用同士 | `[races.md](races.md)` |
| 応用ファイル内の節 | `[現化魔法](magic.md#現化魔法)` |
| 定理内「重要な帰結」節 | `[T5#ビッグバン由来物質の還元不可能性](core/theorems.md#重要な帰結-ビッグバン由来物質の還元不可能性)` |

アンカー名は GitHub の Markdown レンダリングに従う（小文字化、空白のハイフン化）。日本語見出しはそのまま使用可。

**リンク対象**: ID 付き見出し（公理 E/I・定理 T・未解明領域 Q）に限らず、応用ファイル内の任意の見出しを自由に参照してよい。

**見出し改訂時の注意**: 見出しを変更するとアンカーも変わるため、当該見出しへの被リンクが切れる。改訂時は被リンクの有無を確認する。リンク有効性の機械チェックは Phase 1 で整備するスクリプトに任せる。

**特に頻繁に参照されるハブ**: 次の節は複数ファイルから繰り返し参照されるため、改訂時の影響範囲が広い。命題本体を改訂する場合でも、節名を変えるかどうかは慎重に判断する。

- 定理内の「重要な帰結」節（例: T5 内「重要な帰結: ビッグバン由来物質の還元不可能性」、T4 内「優先結合則」、T3 内「危険性」、T2 内「特殊事例: ビッグバン」）
- 応用ファイル内の参照対象節（例: `spellcraft.md`「術式の定義」、`spellcraft.md`「ワープ」、`magic.md`「人代における魔法」）

**禁止事項**: 命題（公理 E/I・定理 T・未解明 Q）を参照する際に、コードのみ（`T1`、`[T1]`、`E4` など）の表記は使わない。必ず **セクション名を含めたリンク** で書く。

- ❌ NG: `T1`、`[T1]`、`（T7 魔法）`、本文中の「I1 により…」
- ✅ OK: `[T1 エネルギー保存則](theorems.md#t1-エネルギー保存則)`
- ✅ OK（shortcut reference 形式）: `[T1 エネルギー保存則]` を本文で使用し、ファイル末尾に `[T1 エネルギー保存則]: theorems.md#t1-エネルギー保存則` を定義

範囲・列挙も例外としない。「T1〜T6」「T1, T5, T7」のように特定の命題群を指す場合は両端または各要素をリンクで書く（例: `[T1 エネルギー保存則] 〜 [T6 ...]`）。ID 採番の説明・廃止リスト・テンプレート例示でプレースホルダーとして書く場合は、引用（`>`）またはコードブロックに入れる。

### 4.5 未解明領域の本文構造

```markdown
### [Q1] 名称

**背景**: 既知の事実と未解明部分の境界を述べる
**現在判明していること**: 観測事実、関連する組織の認知レベル
**この空白の意図**: 物語ギミック・派生作品での活用例
**関連**: 関連する公理・定理・応用ファイル
```

### 4.6 観測事実の扱い

観測事実（メカニズムは明らかでないが、現象として観察される事項）は、性質に応じて置き場所を変える。

| 観測事実の種類 | 置き場所 | 例 |
|---|---|---|
| 公理・定理の本性に近い性質 | 当該公理・定理の本文に 1〜2 文 | 原初返り（[E6 精神エネルギー] の波長分布の偏りとして） |
| 特定ドメインに紐づく現象 | 該当応用ファイル | ダンジョン内での瘴気蓄積（dungeons.md）、ケース C 道具の出現（artifacts.md） |
| 大規模で独立した現象群 | 専用の応用ファイル | 種子から発芽した各種族の特性（races.md） |
| メカニズム不明部分 | Q として登録 | 原初返りの発生メカニズム → [Q1 波長操作] |

運用ルール:

- 公理・定理の本文での言及は **1〜2 文** に留める。それを超える詳細は応用ファイルへ移し、本文からはリンクする
- メカニズム不明部分は必ず Q を立てて切り分け、本文に「謎」を抱え込まない
- 観測事実を定理に置くのは原則避ける（定理は論理的に導出されるもの、観測事実は経験的に観察されたもの）。観測される規則性が公理から論理的に説明できると判明した場合は、その時点で定理に格上げする

### 4.7 文体

- 「である」調で簡潔に
- 命題本体は 1〜2 文以内
- 詳細はリスト形式を許容（読みやすさ優先）
- 命題内で対象を指す場合は ID を併記する（例: 「個体（[E4 個体]）」）
- 中学生〜の読者を想定し、数学・論理学の専門用語に依存しない（「補題」「系」等は本文に書かない）

### 4.8 図の管理

- 図は `world/images/` に配置
- ソース（drawio 等）と書き出し（svg）の両方を含める
- キャプション・凡例は本文側に記す
- 体系の全体図は `world/README.md` に集約

## 5. 公理（存在に関するもの）の設計

### [E1] 現界

**命題**: 物理法則に従う 3 次元時空が存在する。

**書くべき内容**:
- 個体（[E4 個体]）が存在する場としての位置づけ
- 真界（[E2 真界]）との関係で機能する特有の法則（マナ、精神エネルギー、魂）が存在することを予告
- 物理エネルギーの種類: 力学、電磁気、熱、化学、光・放射線、核
- 物理法則は本作の枠組みに必要な範囲で言及するに留め、詳細は読者の物理直感に委ねる

**関連**:
- → [E2 真界], [E4 個体], [I1 変換則], [T1 エネルギー保存則]

**design-notes.md に切り出す事項**:
- 物理法則を読者の現実世界と酷似させる選択

---

### [E2] 真界

**命題**: 現界とは別次元の空間が存在する。

**書くべき内容**:
- 現界の 3 次元空間とは独立した次元であること
- マナ（[E3 マナ]）が存在する場
- 現界の 3 次元座標との対応関係（メタファー: 球体の表面が現界座標にマッピングされる）
- 真界内でのマナの濃淡分布。濃淡の変動は数千〜数万年単位で緩慢
- マナの総量は膨大（真界 》 宇宙全体エネルギー 》 惑星エネルギー）
- 内部構造の詳細は未解明（→ [Q3 真界の内部構造]）

**関連**:
- → [E1 現界], [E3 マナ], [E5 魂], [Q3 真界の内部構造]

**design-notes.md に切り出す事項**:
- 真界を「球体の表面が現界座標にマッピングされる」メタファーで描写する選択

---

### [E3] マナ

**命題**: 真界には純粋ポテンシャルエネルギー（マナ）が存在し、あらゆる物理エネルギー・物質に変換可能である。

**書くべき内容**:
- 「純粋ポテンシャルエネルギー」の意味（あらゆる物理エネルギーに変換可能な可能性そのもの）
- 物質の生成も可能であること
- マナのままで現界に取り出すことはできない（変換は [I1 変換則] による）
- 真界の中で濃淡があり（[E2 真界] を参照）、扱える量は局所的なマナ濃度と魂の大きさで決まる

**関連**:
- → [E2 真界], [I1 変換則], [I2 共鳴則], [Q6 マナ濃淡変動]

---

### [E4] 個体

**命題**: 現界には境界と持続性を持つ物質単位（個体）が、入れ子構造で存在する。

**書くべき内容**:
- 個体の 2 要件: 境界（他と区別される）+ 持続性（時間的に同一性を保つ）
- 入れ子構造の例: 細胞 ⊂ 人 ⊂ 社会 ⊂ 国家 ⊂ 地球 ⊂ 宇宙
- 規模の幅は極めて広い（細胞から宇宙まで）
- 一部の個体（思考・意思を持つもの）は精神エネルギー（[E6 精神エネルギー]）を発生させる
- 個体は固有の魂（[E5 魂]）を持つ

**関連**:
- → [E5 魂], [E6 精神エネルギー]

---

### [E5] 魂

**命題**: 個体ごとに固有の形を持つ、真界と現界の接点（魂）が存在する。

**書くべき内容**:
- 魂の役割: 真界と現界をつなぐ「孔」
- 個体ごとに固有の**形**を持つ（変換できるマナの方向に影響）
- 個体ごとに固有の**大きさ**を持つ（一度に扱えるマナ量の上限を決める）
- 大規模な個体（地球、惑星）ほど大きな魂を持つ
- 死後の魂の行方は未解明（→ [Q4 死後の魂]）

**関連**:
- → [E4 個体], [E6 精神エネルギー], [T2 共鳴現化], [T6 同調], [Q4 死後の魂]

---

### [E6] 精神エネルギー

**命題**: 個体は、波長・強さ・方向の 3 属性を持つエネルギー（精神エネルギー）を発生させる。思考・意思を持つ個体ほど発生量が多い。

**書くべき内容**:
- **波長**: 真界寄り / 現界寄り の連続スペクトル。マナとの共鳴のしやすさを決める
- **強さ**: 一度に発生させられる総量。意思の強さ・知性の深さに依存
- **方向**: 変換時にマナがどのエネルギー・物質へ向かうかを決める
- 単一個体の精神エネルギーだけでなく、複数個体の**集合無意識**も精神エネルギーとして機能する
- **観測事実**: 進化を経た種族から、特異的にルーツが近い波長を持つ個体が生まれることがある（原初返り）。1 世代に 2〜3 人程度の頻度で発生
- 原初返りの発生メカニズム、および波長を人為的に真界寄りにする方法は未解明（→ [Q1 波長操作]）

**関連**:
- → [E5 魂], [I2 共鳴則], [I4 作用則], [T2 共鳴現化], [T5 存在強度], [Q1 波長操作]

**design-notes.md に切り出す事項**:
- 「集合無意識も精神エネルギーとして機能する」という選択（既存の慣用語と意味が異なるため）
- 原初返りの発生頻度を「1 世代に 2〜3 人」とする選択

## 6. 公理（相互作用に関するもの）の設計

### [I1] 変換則

**命題**: マナが現界に現出する瞬間、必ず物理エネルギーまたは物質に変換される。

**書くべき内容**:
- マナのままでは現界に存在できない
- 変換先は物理エネルギーまたは物質（マナ自体は留まれない）
- 変換の方向性は精神エネルギー（[E6 精神エネルギー]）を介して与えられる（→ [I2 共鳴則]）
- 媒介なしに発生する場合もある（→ [T3 自然現化]）

**関連**:
- → [E3 マナ], [I2 共鳴則], [I3 副産則], [T2 共鳴現化], [T3 自然現化]

---

### [I2] 共鳴則

**命題**: 精神エネルギーはマナと共鳴し、マナの変換の触媒として機能する。

**書くべき内容**:
- 触媒としての精神エネルギーの役割
- 共鳴の効率を決める要素: 精神エネルギーの波長（マナとの近さ）、方向（変換先との整合）、魂の形（マナの取り出し経路との適合）
- 魂を経由する共鳴（[T2 共鳴現化]）と、経由しない経路（[T3 自然現化]）の区別
- 共鳴は逆方向にも作用する（マナへの還元、→ [T4 マナ還元]）

**関連**:
- → [E5 魂], [E6 精神エネルギー], [I1 変換則], [T2 共鳴現化], [T4 マナ還元]

---

### [I3] 副産則

**命題**: マナの変換に伴い、対となる瘴気が発生する。瘴気は物質・エネルギーと結合してマナへ戻る。

**書くべき内容**:
- **瘴気の定義**: マナから物理エネルギー・物質を生成した際に発生する副産物
- 物理学の反物質と類似するが、即時対消滅ではなく存在強度に応じて結合のしやすさが変わる
- 結合してマナに戻る現象は[T4 マナ還元]として定理化される
- 瘴気は存在強度の低い個体には毒として作用する（体をむしばむ）
- 大量の瘴気は環境に残留しうる

**関連**:
- → [I1 変換則], [T1 エネルギー保存則], [T4 マナ還元], [T5 存在強度]

---

### [I4] 作用則

**命題**: 精神エネルギーは他個体（およびその魂）にも作用しうる。

**書くべき内容**:
- マナを介さない、直接的な精神エネルギーの伝達経路
- 作用の形態: **感応**（他個体の情報・感覚を受信）、**支配**（他個体の状態・行動に変化を加える）
- 同調（[T6 同調]）の前提となる
- 超能力（[T9 超能力]）はこの作用を体系化したもの

**関連**:
- → [E5 魂], [E6 精神エネルギー], [T6 同調], [T9 超能力]

## 7. 定理の設計

### [T1] エネルギー保存則

**命題**: 「真界のマナ＋現界の物質・エネルギー＋現界の瘴気」の総量は常に一定である。

**導出元**: [I1 変換則] + [I3 副産則]

**書くべき内容**:
- 証明スケッチ:
  - [I1 変換則] により、マナは現界に出る瞬間に物理エネルギーまたは物質に変換される（マナ減 = 物質・エネルギー増）
  - [I3 副産則] により、変換時には対となる瘴気が発生する（物質・エネルギー増 + 瘴気増 が保存）
  - 瘴気がマナに戻る場合も同様（瘴気減 + 物質・エネルギー減 = マナ増）
- 現界単体で見た場合の対称性: 瘴気の総量 = 現化した物質・エネルギーの総量
- 存在強度（[T5 存在強度]）で保持されている物質も、対となる瘴気は真界との境界付近に残留する

**関連**:
- → [T4 マナ還元], [T5 存在強度]

---

### [T2] 共鳴現化

**命題**: 魂を経由した精神エネルギーがマナと共鳴することで、マナが物質またはエネルギーとして現界に現出する。

**導出元**: [E5 魂] + [E6 精神エネルギー] + [I1 変換則] + [I2 共鳴則]

**書くべき内容**:
- 経路: 真界のマナ → 魂（孔） → 精神エネルギー（触媒・共鳴） → 物理エネルギーまたは物質
- 効率を決める要素:
  - 精神エネルギーの量（規模）
  - 精神エネルギーの波長と方向（変換効率）
  - 魂の大きさ（一度に扱えるマナの上限）
  - 魂の形と方向の適合度
- 自分自身の精神エネルギーを使う場合は[T7 魔法]、術式で変換した精神エネルギーを使う場合は[T8 魔術]、他個体の魂を使う場合（条件あり）は魔法の中に含む

**含めるべき節**:

#### 特殊事例: ビッグバン

- 「現界」自体を一つの個体（[E4 個体]）と見たとき、現界自身の精神エネルギーで行使された共鳴現化が宇宙の起源（ビッグバン）である
- ゆえに**ビッグバンは魔法**である（[T7 魔法] の最大事例）
- ビッグバンで生成された物質は「現界」の精神エネルギーで存在強度が極限に保たれる（→ [T5 存在強度] 内「重要な帰結」）
- 「ビッグバン由来の物質」は本世界における特殊な分類として、応用ファイルで頻繁に参照される

**関連**:
- → [T5 存在強度], [T7 魔法], [T8 魔術]

---

### [T3] 自然現化

**命題**: 真界でマナが極端に濃くなった場合、精神エネルギーの媒介なしに現界へ染み出すことがある。

**導出元**: [I1 変換則]（[I2 共鳴則] を経由しない経路として）

**書くべき内容**:
- 発生条件: 真界の局所的なマナ濃度が極端に高い
- 自然災害的現象として現れる（火山噴火、異常気象の一部）
- 発生は予測不能
- 共鳴現化（[T2 共鳴現化]）と異なり、媒介となる精神エネルギーがないため変換の方向性は確率的

**含めるべき節**:

#### 危険性

- 自然現化で生成された物質・エネルギーは精神エネルギーの裏付けがなく、存在強度（[T5 存在強度]）が極めて低い
- 即座に瘴気と反応してマナに戻ろうとする
- その過程で周囲の**存在強度の低い物質**を巻き込んでマナ還元してしまう（[T4 マナ還元]「優先結合則」）
- ゆえに自然現化は周囲の生態系・建造物に対して破壊的でありうる

**関連**:
- → [T4 マナ還元], [T5 存在強度], [Q6 マナ濃淡変動]

---

### [T4] マナ還元

**命題**: 瘴気が物質または物理エネルギーと結合することで、マナの状態に戻り真界に収められる。

**導出元**: [I3 副産則] + [T2 共鳴現化]

**書くべき内容**:
- 還元のメカニズム: 瘴気 + 物質・エネルギー → マナ（真界へ）
- 自然発生する場合（瘴気と低存在強度の物質の自然反応）と、触媒として精神エネルギーを使う場合（真化魔法・真化魔術）がある
- 還元のしやすさは対象の存在強度（[T5 存在強度]）に依存

**含めるべき節**:

#### 優先結合則

- 瘴気は周囲の最も**存在強度が低いもの**から優先的に結合する
- 結合先がない場合（周囲が全て高存在強度）は瘴気として残留する
- この性質は次の現象を生む:
  - 魔法で生成した低存在強度の物質は通常より速く消滅する
  - 瘴気が蓄積した環境（ダンジョン等）では生成物が安定しにくい
  - 自然現化（[T3 自然現化]）の危険性の根拠

**関連**:
- → [T1 エネルギー保存則], [T5 存在強度], [dungeons.md]

---

### [T5] 存在強度

**命題**: マナから変換された物質・エネルギーは、精神エネルギーの影響を受けた度合い（存在強度）に応じて、瘴気との結合のされにくさが決まる。

**導出元**: [E6 精神エネルギー] + [I3 副産則] + [T2 共鳴現化]

**書くべき内容**:
- 存在強度の定義: 物質・エネルギーが精神エネルギーの影響を受けている度合い
- 存在強度を決める要素:
  - **主要因**: 術者の精神エネルギーの強さ
  - **副次的要因**: 精神エネルギーの方向と魂の形の適合度
  - **影響しない**: 精神エネルギーの波長（規模には影響するが安定性には中立）
- 集合無意識による存在強度（[E6 精神エネルギー]）:
  - 多くの個体から認知されている存在は集合無意識からの精神エネルギー供給を受け、存在強度が高い
  - 例: 万人に知られる聖剣
- マナ由来のエネルギーが既存物質に作用した場合:
  - 既存物質はビッグバン由来の存在強度で保護される
  - 変化部分（温度上昇、構造変化など）の存在強度は術者の精神エネルギー次第

**含めるべき節**:

#### 重要な帰結: ビッグバン由来物質の還元不可能性

- ビッグバン由来の物質は「現界」自体の精神エネルギーで保持されており、存在強度が極限に高い
- マナ還元は実質的に不可能（理論上は「現界」を上回る精神エネルギーが必要だが、それを持つ個体は存在しない）
- 結果:
  - 真化魔法は通常の物質を消滅させられない（[magic.md](../magic.md#真化魔法)）
  - 真化が有効な対象は、魔法・魔術で生み出された存在強度の低い物質に限られる
  - 例外: ワープなど真化と現化を同時に行い総量を保つ操作は「消滅」ではないため抵触しない（[magic.md](../magic.md#転送ワープ)）
  - 例外: 一部の伝説の武具は制限を一部超える可能性が示唆される（[artifacts.md](../artifacts.md#ロンギヌスの槍)）

**関連**:
- → [T4 マナ還元], [T7 魔法], [magic.md], [artifacts.md], [dungeons.md]

**design-notes.md に切り出す事項**:
- 「集合無意識による存在強度」の採用（既存ファンタジーとの差別化）

### [T6] 同調

**命題**: 精神エネルギーが他個体の魂にアクセスし、その個体の情報・感覚・意思に接続する現象。

**導出元**: [E5 魂] + [E6 精神エネルギー] + [I2 共鳴則] + [I4 作用則]

**書くべき内容**:
- 同調の経路: 自分の精神エネルギー → 他個体の魂 → 接続成立
- 接続成立の条件: 波長の近さ、関係性（血縁・同種族・継続的な関わり等）
- 接続後にできること: 情報受信、感覚共有、（条件次第で）意思の伝達
- 双方向性: 完全同調の場合、互いに影響を与え合う
- 規模上限: 自分の魂の大きさ、および対象の魂への到達可能性
- 特殊事例: 代行者・調停者は母体の魂と完全同調できる（[races.md] へ）

**関連**:
- → [I4 作用則], [T9 超能力], [races.md]

### [T7] 魔法

**命題**: 個体が自身の精神エネルギーで[T2 共鳴現化]を行使する場合、これを「魔法」と呼ぶ。

**導出元**: [T2 共鳴現化] の応用（個体自身の精神エネルギーによる行使）

**書くべき内容**（命題のみを core/theorems.md に置く）:
- 自身の精神エネルギーを直接使う
- 効率は破格（変換ロスが小さい）
- 複雑な操作には不向き（精神エネルギーの方向は個体の素養に依存）
- 限定的な条件下では他個体の魂も利用可能（波長の近さが条件）
- 詳細は [magic.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T8 魔術], [magic.md]

### [T8] 魔術

**命題**: 術式によって変換された精神エネルギーで[T2 共鳴現化]を行使する場合、これを「魔術」と呼ぶ。

**導出元**: [T2 共鳴現化] の応用（術式を介した行使）

**書くべき内容**（命題のみを core/theorems.md に置く）:
- 術式は精神エネルギーの波長を特定方向にシフトする人工的プログラム（術式の定義そのものは [spellcraft.md] 冒頭）
- 術式により誰でも同じ現象を発現できる
- 一方で変換ロスにより効率は魔法に劣る
- マナは術式が刻まれた道具の魂を経由して取り出される
- 詳細は [spellcraft.md] に委ねる

**関連**:
- → [T2 共鳴現化], [T7 魔法], [spellcraft.md], [artifacts.md]

### [T9] 超能力

**命題**: 個体が自身の精神エネルギーを、マナを介さずに他個体（およびその魂）に直接作用させる場合、これを「超能力」と呼ぶ。

**導出元**: [I4 作用則] の応用

**書くべき内容**（命題のみを core/theorems.md に置く）:
- マナを扱う術ではなく、魔法・魔術とは作用経路が異なる
- 形態: 感応（受信）・支配（作用）
- 詳細は [psionics.md] に委ねる

**関連**:
- → [I4 作用則], [T6 同調], [psionics.md]

## 8. 未解明領域の設計

### [Q1] 波長を人為的に真界寄りにする方法

**背景**:
- 原初返りの個体は精神エネルギーの波長が真界寄りであることが秘匿組織内で解明されている（→ [E6 精神エネルギー]）
- 一方、波長を人為的にシフトする方法は未発見

**現在判明していること**:
- 原初返りは 1 世代に 2〜3 人発生する（観測事実）
- 発生原理は未解明（偶然発生）
- 人工的に再現を試みる組織が存在するが、成功例はない

**この空白の意図**:
- 物語の中心的なギミック（古代技術の再発見、原初返りの人工生成、組織の暗躍）として活用可能
- 派生作品でこの問いに答えを与えても良い

**関連**: [E6 精神エネルギー], [magic-history.md]

---

### [Q2] 意思を持つ道具（ケース C）の発生原理

**背景**:
- 術式が刻まれた道具のうち、道具自体が意思を持ち精神エネルギーを発生させるケースが存在する（[artifacts.md] ケース C）
- 発生は偶発的で、意図的な製作は事実上不可能

**現在判明していること**:
- 特化した目的・極端な歴史・極めて高い存在強度などが複合した場合に発生しうる
- 一定の傾向はあるが再現条件は不明

**この空白の意図**:
- 伝説の武具の独自来歴を物語ごとに設定可能にする
- 新たな伝説の武具を派生作品で創出する余地

**関連**: [T8 魔術], [artifacts.md]

---

### [Q3] 真界の内部構造の詳細

**背景**:
- 真界はマナが存在する別次元として観測されるが、その内部構造は外部から観測できない

**現在判明していること**:
- メタファーとしては「マナが揺れ動く球体」「球体の表面が現界座標にマッピングされる」
- マナの濃淡変動は長期的（→ [Q6 マナ濃淡変動]）
- 内部に他の構造（個体、領域分割など）があるかは不明

**この空白の意図**:
- 異界探訪、真界からの干渉者など、真界を舞台とした物語の余地

**関連**: [E2 真界]

---

### [Q4] 死後の魂の行方

**背景**:
- 個体には固有の魂が存在する（[E5 魂]）
- 個体が死亡した後、魂がどうなるかは未定義

**現在判明していること**:
- 死亡個体の魂を直接使用する事例は確認されていない
- 死亡個体の精神エネルギーが集合無意識として残る現象は観測される（存在強度との関係）

**この空白の意図**:
- 死霊・幽霊系の能力、転生、死後の世界などの設定を派生作品で導入可能

**関連**: [E5 魂], [T5 存在強度]

---

### [Q5] 複数現界（並行世界）の有無

**背景**:
- 本作の「現界」（[E1 現界]）は単一の 3 次元時空として記述されている
- 別の現界が存在するかは未定義

**現在判明していること**:
- 本作内では並行世界の存在を肯定も否定もしていない
- 仮に複数現界があるとしても、相互の干渉は観測されていない

**この空白の意図**:
- 並行世界もの、異世界転移などの物語に流用可能

**関連**: [E1 現界]

---

### [Q6] マナの濃淡変動の長期周期性

**背景**:
- 真界のマナ濃度は数千〜数万年単位で緩慢に変動する（[E2 真界]）
- 周期性があるか、純粋に確率的か、外的要因に依存するかは不明

**現在判明していること**:
- 短期的な変動は観測されない
- 長期的にはマナの「豊穣期」「枯渇期」が存在しうるが、本作の時間軸では明確に区分されていない

**この空白の意図**:
- マナ枯渇・豊穣を契機とする時代区分の創出
- 古代の魔法体系がマナ豊穣期を前提とした設定として再解釈可能

**関連**: [E2 真界], [E3 マナ], [T3 自然現化]

## 10. メンテナンス

### 10.1 命題の追加・改訂

**新たに公理・定理・未解明領域を追加する場合**:

1. §2 の分類に従って種別を判定
2. 該当ファイルの末尾に追加し、最大番号 + 1 を採番
3. 本書（architecture.md）の該当節（§5〜§8）に設計を追加
4. glossary.md にエントリを追加（カテゴリタグ付き）
5. 既存命題からの参照リンクを必要に応じて更新
6. 影響を受ける応用ファイルの「前提」「関連」リストを更新
7. 公準的事項があれば design-notes.md にエントリを追加

**既存命題を改訂する場合**:

1. 本書の該当節を先に更新
2. 命題本体を改訂
3. 依存する下流（応用、定理内の重要な帰結節）を全て点検
4. 命題の本質を変えない改訂では ID とアンカー名を維持する

**昇格・降格**:

| 変化 | 操作 |
|---|---|
| 未解明 → 定理 | 答えを与える場合に昇格。新 T# を採番し、Q# は「→ T# として解明」と記録して保持 |
| 定理 → 公理 | 世界の根本前提とみなされる場合に昇格（極めて稀） |
| 応用内の概念 → 定理 | 応用内で導入した概念が複数応用から参照され、世界法則として機能していると判明した場合 |

### 10.2 整合性チェック観点

レビュー時に確認する観点:

- **重複**: 既存命題と意味的に重複していないか（glossary.md で類似概念を検索）
- **分類判定**: 公理／定理／未解明領域／応用の判定が §2 に従っているか
- **導出元の妥当性**: 導出元の公理・定理から命題が論理的に導かれるか
- **波及**: 既存の定理・応用に矛盾を生じないか
- **相互参照**: 関連命題のリンクを更新したか
- **アンカー維持**: 定理内「重要な帰結」節および応用ファイル内の参照対象節のアンカーを変更していないか
- **glossary.md / design-notes.md 反映**: 新概念・公準的事項をそれぞれ反映したか
- **派生作品からの視点**: 改変ポイントが design-notes.md に明示されているか
- **物語利用者の視点**: 戦闘・能力・キャラクター設計のルールが早引き可能か
- **未来執筆者の視点**: 「これは Q# として認識されている空白か、単に書かれていない領域か」が判別可能か

### 10.3 廃止のルール

- 廃止された ID は再利用しない
- ファイル内に `[廃止] X# 旧名称 — 廃止理由・移動先` を残す
- glossary.md からは削除可能（重複防止のため）

### 10.4 新分類の追加

4 分類（E/I/T/Q）で扱いきれない命題が出てきた場合、新分類の追加は本書の改訂を伴う。安易に追加せず、まず既存分類で扱えないか検討する。
